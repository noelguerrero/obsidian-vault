
|**Command**|**Example**|**What it Does**|
|---|---|---|
|`dir`|`dir`|Lists all files and folders in the current directory.|
|`cd directory`|`cd Documents`|Moves into the **Documents** folder.|
|`cd ..`|`cd ..`|Moves up one folder level.|
|`cd \`|`cd \`|Returns to the root of the drive (e.g., `C:\`).|
|`copy source destination`|`copy notes.txt D:\Backup`|Copies `notes.txt` to the `D:\Backup` folder.|
|`del filename`|`del test.txt`|Deletes `test.txt`.|
|`find`|`find "Hello" notes.txt`|Searches for the word **Hello** inside `notes.txt`.|
|`mkdir directory`|`mkdir Projects`|Creates a folder named **Projects**.|
|`ren oldname newname`|`ren old.txt new.txt`|Renames `old.txt` to `new.txt`.|
|`help`|`help`|Displays all available MS-DOS commands.|
|`help command`|`help dir`|Shows detailed information about the `dir` command.|
