
## Sysmon
**Sysmon (System Monitor)** is a **free Windows tool from Microsoft** that watches what’s happening inside a Windows machine and writes very **detailed security logs**.

## Splunk
- It is a tools that helps the you to collect, search, and understand machine data (logs) that produce by the computer.
- It translate the logs of your computer and then gives you an answers.

**Splunk can:**

- Collect logs from systems (Windows, Linux, apps, firewalls)
- Store them in an indexed, searchable way
- Let you run searches like:
    - “Show me all programs that ran today”
    - “Which process opened a network connection?”
- Create dashboards and alerts
- Help detect attacks and troubleshooting issues
