## No API Connection Issues
if you encouter API connection issue in wazuh 

- first check if the wazuh-manager, wazuh-indexer, wazuh-dashboard is running
```bash
sudo systemctl status wazuh-manager --no-pager
```

- if they not running, start each of those 3
```bash
sudo systemctl start wazuh-manager --no-pager
```

- If they running but still no API connection, just restart those 3.
```bash
sudo systemctl restart wazuh-manager --no-pager
```

## Security Information Management (SIM)

### 🔒 Security Events

This is where you'll spend most of your time.

**Purpose:**

- View security alerts generated by Wazuh agents.
- Detect suspicious activities, attacks, policy violations, and system issues.

**Examples:**

- Multiple failed login attempts
- New user account created
- Malware detection
- SSH brute-force attacks
- Service stopped unexpectedly

Think of it as the **"Security Alert Center."**


### 📄 Integrity Monitoring

Also called **File Integrity Monitoring (FIM).**

**Purpose:**

- Watches important files and directories.
- Alerts when files are created, modified, deleted, or renamed.

**Examples:**

- `/etc/passwd` changed
- Windows Registry modified
- Malware alters a system file
- Configuration files edited

**Why important?**  
Attackers often modify files after gaining access. This module helps detect those changes.

## Auditing and Policy Monitoring


### 📋 Policy Monitoring

Checks whether systems follow security policies.

**Purpose:**

- Compare system configurations against security baselines.
- Detect insecure settings.

**Examples:**

- Password policy too weak
- Firewall disabled
- Unnecessary services running
- Root login enabled

Think of it as:

> "Are my systems configured according to security best practices?"


### 👤 System Auditing

Tracks user and system activities.

**Purpose:**

- Monitor commands executed.
- Monitor user actions.
- Track privilege escalation.

**Examples:**

- User runs `sudo`
- New user added
- File permissions changed
- Service started/stopped

Very useful during incident investigations.


### 🛡️ Security Configuration Assessment (SCA)

One of Wazuh's strongest features.

**Purpose:**

- Automatically checks system security settings.
- Compares them against standards like CIS Benchmarks.

**Examples:**

- SSH configuration secure?
- Password complexity enabled?
- Unused accounts disabled?
- Firewall configured?

Instead of manually checking hundreds of settings, Wazuh does it automatically.

## Threat Detection and Response

### 🚨 Vulnerabilities

Scans installed software for known vulnerabilities.

**Purpose:**

- Identify software with known CVEs.
- Show severity levels.

**Examples:**

- Outdated OpenSSL
- Vulnerable Apache version
- Old Linux kernel

A vulnerability entry typically shows:

- CVE ID
- Severity
- Affected package
- Description

Example:

```
CVE-2025-XXXXPackage: opensslSeverity: High
```


### 🎯 MITRE ATT&CK

Maps security alerts to attacker techniques.

**Purpose:**

- Understand attacker behavior.
- Classify alerts using the MITRE ATT&CK framework.

For example:

|Attack Activity|MITRE Technique|
|---|---|
|Brute Force Login|T1110|
|PowerShell Abuse|T1059|
|Credential Dumping|T1003|
|Persistence via Startup|T1547|

This helps answer:

> "What is the attacker trying to do?"

instead of just seeing raw alerts.

## Regulatory Compliance

These modules help organizations prove compliance with security standards.

### 💳 PCI DSS

For companies handling credit card data.

Checks:

- Logging
- Monitoring
- Access control
- Security policies


### 🏛️ NIST 800-53

U.S. government security framework.

Checks controls related to:

- Access management
- Incident response
- Auditing
- Risk management

### 🤝 TSC (Trust Services Criteria)

Used in SOC 2 audits.

Focuses on:

- Security
- Availability
- Confidentiality
- Integrity
- Privacy

### 🔐 GDPR

European privacy regulation.

Helps monitor:

- Personal data protection
- Access logging
- Security controls

### 🏥 HIPAA

Healthcare compliance standard.

Focuses on:

- Patient data protection
- Audit logging
- Access monitoring
