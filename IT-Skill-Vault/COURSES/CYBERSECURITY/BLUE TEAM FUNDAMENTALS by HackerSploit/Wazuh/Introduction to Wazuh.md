## Wazuh
- free and open source platform used to threat detection, prevention and response.
- used to protect networks, virtualized environments, containers and cloud environments.
- In blue team operations, Wazuh is a SIEM (Security Information Event Management) system that is used to collect, analyze, aggregate (or gets data), index and analyze security related data 
- allows you to detect intrusions, attacks, vulnerabilities, and malicious activity.
- It tells the security enginneer that:
	- there is someting going on this system
	- this what happened
	- this is where attack originated from

## How does Wazuh Works
It consists of the following components

#### Wazuh Agent
- Cross platform endpoint security agent (or progam/software) that is installed on the system/host you would like to monitor.
- basically it is a small program or software installed on the computer that sends security and system information to the "wazuh server".

#### Wazuh Server
- It analyze the data received from the wazuh agents, process this data and matches it against rule-sets to identify indicators of compromise (IOCs).

#### Elastic Stack
- It displays the indexes the alerts generated by the wazuh server and provides users with robust data visualization and analysis functionality
- Sometimes called ELK stack, it is a collection of tools for handling logs and data.
	- E - Elasticsearch (handles analytics)
	- L - Logstash (handles the data processing pipeline and gets data on multiple resources simulataneously)
	- K - Kibana (visualize data in form of chart or graph)


**Simple explanation:**
- **Wazuh Server** - Analyze and detect threats
- **Wazuh agents** - Collects security events
- **Elastic Stack** - Stores and display the data 

**Note:** Wazuh can also be used to monitor devices like networking equipment that cannot run the Wazuh agent. This works by getting the devices to send their logs to Wazuh server.

## Deploying Wazuh
**Wazuh can be deployed in two ways:**
#### 1. All-in-one
Wazuh server and ELK strack are installed and configured on the same system or server.
- Wazuh provides users with a pre-built all in one OVA file that you can setup to your local network.

#### 2. Distributed
Each component is setup on a separate server. This is typically suitable for lager environments for the purpose of scalability.

****
