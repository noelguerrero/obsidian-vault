
## What is Splunk
- it is a powerful platform that used to analyze data and logs produced by the system.
- it allows you to monitor, search and analyze machine generated data and logs through web interface.
- In order to use splunk, you need to utilize splunk universal forwarder to forward logs and data to splunk for analysis.
- It provides robust visualization and reporting tools that allows you to identify specific data.

****
## Splunk for security event monitoring
- Splunk Enterprise Security (Splunk ES) is a SIEM solution that used by security teams to quickly detect and respond to internal and external attacks.
- Splunk ES can be used for security event monitoring, incident response, and running a SOC.
