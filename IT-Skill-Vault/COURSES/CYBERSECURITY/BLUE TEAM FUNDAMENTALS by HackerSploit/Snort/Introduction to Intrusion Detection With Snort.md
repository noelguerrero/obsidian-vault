## Intrusion Detection Systems (IDS)
- is the process of actively discovering threats/attacks/intrusions on a network, host pr services.
  
- There are 2 types of IDS solutions based on the placement:
	- **Host-based IDS (HIDS)** - is a setup on an individual host on a network.
	- **Network IDS (NIDS)** - is place within a network to monitor traffic to and from all hosts on a network.
	  
- It is a security tool that monitors network traffic or system activity to detect suspicious behavior, attacks, or policy violation. Also it notifies a certain party  to inform them about the intrusion.
  
- Intrusion detection systems are typically coupled with the functionality to also perform intrusion prevention, whereby specific rules can be set to drop packets that are malicious or intrusive.
