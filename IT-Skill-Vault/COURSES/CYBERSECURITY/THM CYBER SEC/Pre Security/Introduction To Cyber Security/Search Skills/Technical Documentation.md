One vital skill to acquire is to look up official documentation.


## Linux Manual Pages
- Manual page or man-page in short for linux.
- Each command is expected to have a man page.
- man pages also exist for system calls, library functions, and even configuration files.


Let’s say we want to check the manual page for the command `ip`. We issue the command `man ip`. The screenshot below shows the page we received. You might want to start the AttackBox and run `man ip` on the terminal. Press `q` to quit.
