
## Examples of Specialized Search Engines


### Shodan 
- search engine for internet-connected devices
-  It allows you to search for specific types and versions of servers, networking equipment, industrial control systems, and IoT devices
- **Shodan it basically search hardwares.**

Instead of searching _pages_, Shodan searches things like:
- servers
- routers & firewalls
- webcams
- IoT devices (smart TVs, printers, etc.)
- databases exposed to the internet

![[Pasted image 20260126193932.png]]


 **What does Shodan show?**

When it finds a device, it can show:
- IP address
- Open ports (e.g., 22, 80, 443)
- Running services (SSH, FTP, HTTP, RDP, etc.)
- Software versions
- Sometimes banners or login prompts

****

### Censys
- It appear similar to shodan but it focuses on internet-connected hosts, wesites, certificates, and other internet assets.
- **Censys basically searches _hosts_**.


![[Pasted image 20260126195124.png]]

**Censys search Internet assets (infrastructure)**
- IP addresses
- Domains & subdomains
- SSL/TLS certificates
- Services running on those IPs
