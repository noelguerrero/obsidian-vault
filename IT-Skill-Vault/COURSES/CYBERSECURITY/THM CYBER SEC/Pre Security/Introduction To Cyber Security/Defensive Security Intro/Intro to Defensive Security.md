
## Defensive Security
- also known as blue teaming

**Real life example of poor security:**

- **British Airways (2018)**

	Personal details such as birth names, addresses, and payment card details of 400,000+ customers were leaked. 

	British Airways was fined £20 million for this incident.

- **Marriott International (2020)**

	The passport information, payment card details, and names of 334 million customers were leaked, partly due to outdated systems.

	Marriott International settled a $52 million lawsuit.


### Key Areas of Defensive Security

#### A. Monitoring and Detecting
Continually observing network and system activity to detect suspicious behaviour and events.

These may include, for example, monitoring for logins from another country while the employee is based in the company's London office.

#### B. Incident Response
The team quickly comes together if suspicious activity is confirmed and alerts are raised.

This is when the **Incident Response** process begins. The process involves containing and removing the threat and restoring the business back to normality.

#### C. Threat Intelligence
Gathering and using information about attackers—their latest methods, targets, and trends—can greatly strengthen an organisation’s defences.

For example, understanding that an attacker focuses on a specific software application used within organisations.

#### D. Vulnerability Management
Fixing software or system flaws is an important preventative measure that can lower the risk of an attack.

Security teams can check which systems attackers are most likely to target. This can be done manually or with the help of automated tools.

#### E. Investigation Analysis
Members of a defensive security team are always monitoring and analysing what’s happening inside an organisation.

They work to separate normal activity from suspicious behaviour, digging into the details like solving a puzzle to uncover valuable insights.


### Roles and Responsibilities that will find in defensive security team

#### 1. SOC Analyst
Frontline of protecting the organization, it monitors events on the organization's network and system to identify suspicious behavior.

#### 2. Incident Responder
Responsible for investigating and responding to ongoing security incidents within the organization.

#### 3. Security Engineer
Develops and maintains the essential tools and systems that support the defensive security team.

#### 4. Digital Forensics
They will gather, preserve, and analyze evidence from the network and systems to uncover vital information about the attackers and their methods.


### Defensive Security in Practice
Organizations don't rely on the single tool or method to secure, they build layers of defense this call it "Defense Depth" meaning if one security fails, we have others to rely upon various stages

**Defensive Measures include:**

- **Employee training** -  training employees to be proactive in recognising attempts for things like phishing is essential.

- **Intrusion Detection Systems (IDS)** - These devices act as surveillance cameras across the organization's IT. They Monitor and alert when suspicious behavior or activity detected across the network or system.

- **Firewall** - It act as security guards on an organization's network, it monitor and determine what traffic is allowed to enter or rejected to the network.

- **Security Policy** - It helps the organizations to ensure that their system is used correctly (Blocking access to dangerious website, requiring strong passwords, etc).


### Common Tools that used by Defensive Security Teams Worldwide.
Defensive Security Teams rely on wide range tools and technologies.

#### Security Operations Centre (SOC)
It is a centralize unit within an organization that manages, monitors, and improves an overall security posture. It serves as a command center where people, processes, and technology work together to identify and respond to cybersecurity threats in real-time.

**A typical day in the SOC could look like:**
- Reviewing alerts triggered by security tooling
- Investigating anomalies
- Responding to incidents

These professionals are often the eyes and ears on the frontline for protecting an organisation.


#### SIEMs: The Defensive Security Radar
- Security Information and Event Management systems (SIEMs) are the central place for all data and information collected from security devices, workstations, servers, and more within an organization.

- It is like a radar sweeping the digital environment, these systems are an absolutely critical part of any organization's defensive security, as they offer insight into what is happening within the organization's IT.
