## TLD (Top Level Domain)
It is a right hand part of the domain **ex**: `tryhackme.com` it is the `.com`

### There are two types of TLD

**gTLD (Generic Top Level Domain)** - It tell the domain name purpose. 

**Ex:**
- `.com` - for commercial
- `.org` - for organization
- `.edu` - for education

**ccTLD (Country Code Top Level Domain)** - It was used for geographical purposes.

**Ex:**
- `.ph` sites based on Philippines
- `.ca` sites based on Canada


## Second Level Domain
It is actually the name of the website, like **Facebook** in `facebook.com` 
- Can only use a-z, 0-9, and hyphenes
- But cannot start and end in hypens


## Subdomain
It is the left-hand side of the Second Level Domain.

**Example:**
`admin.tryhackme.com` it is the admin part of `tryhackme.com`
You can used multiple subdomain but limited into 63 characters.
