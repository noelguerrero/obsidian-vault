
## DNS Record Types

DNS isn't just for websites though, and multiple types of DNS record exist. We'll go over some of the most common ones that you're likely to come across.

- **A** - It translates a domain name into an IPv4 address, for example 104.26.10.229
- **AAAA** - It translates a domain name into an IPv6 address, for example 2606:4700:20::681a:be5.
- **CNAME** - makes one domain name an alias of another domain name or it directs into another name. 
	**Ex.** `www.nortecafe,com` -> `nortecafe.com`
- **MX (Mail Exchange)** - It tells the internet which mail server is responsible for receiving emails for a domain.
- **TXT** - It allows domain owners to attach text data to a domain, usually for **verification and security purposes**.
