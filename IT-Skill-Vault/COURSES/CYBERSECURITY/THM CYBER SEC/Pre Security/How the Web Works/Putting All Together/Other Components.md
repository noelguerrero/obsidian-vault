## Load Balancer
It is like traffic manager of a website that ensure it can handle high traffic and also it provide a failover if the server becomes unresponsive.

When you request a website, the load balancer will receive your request first and then forward it to one of the multiple servers behind it.

**Health check** - the load balancer perform periodic checks with each server to ensure they are running correctly.

## CDN (Content Delivery Networks)
It makes the website **load the resources faster by serving content from locations closer to the user**.


## Databases
The websites can communicate with databases to store a recall data from them.


## WAF (Web Application Firewall)
It sits between Web request and web server, it protect webserver from hacking or denial service attack by analyzing and dropping the web requests that are potentially attacking the web server.
