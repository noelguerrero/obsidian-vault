
**HTTP (HyperText Transfer Protocol)** 
- Is a set of rules for communication between web browser (client) and web server for transmitting webpage data (HTML, images, videos, etc).
- Develop by Tim Berners-Lee 

**HTTPS (HyperText Transfer Protocol Secure)**
- Secure version of HTTP.
- HTTPS data is encrypted, and gives you assurance that you communicating to the correct web server.
