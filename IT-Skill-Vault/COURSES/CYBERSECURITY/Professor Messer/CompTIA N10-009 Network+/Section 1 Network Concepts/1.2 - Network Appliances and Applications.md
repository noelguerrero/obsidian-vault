
## Networking devices
- Many different ways to forward traffic
	-  A data center full of equipment

- Every device have a purpose  
	- The implementation may change over time
	- Once installed, it can be difficult to remove

- There are new technologies all the time
	- Always something to learn

****
## Router
**Routes traffic between IP subnets**
- OSI layer 3 device
- Routers inside of switches sometimes called "layer 3 switches"
- Layer 2 = Switch, Layer 3 = Router

**Often connects diverse network types**
- LAN, WAN, copper, fiber

****
## Switch
![[Pasted image 20260410210338.png]]

**Bridging done in hardware**
- Application-specific integrated circuit (ASIC)

**An OSI layer 2 device**
- Forwards traffic based on data link address

**Many ports and features**
- The core of an enterprise network
- May provide Power over Ethernet (PoE) -  It is a technology that lets a single **Ethernet cable** carry both: data/network connection, and electrical power

**Multilayer switch**
- includes layer 3 (routing) functionality

****
## Firewalls (hardware)

![[Pasted image 20260410211103.png]]

**Filter traffic by port number or application**
- traditional vs NGFW (Next Generation Firewall)

**Encrypt traffic**
- VPN between sites

**Most firewalls can be layer 3 devices (routers)**
- often sits on the ingress and egress (incoming traffic and Outgoing traffic) point of the network
- Network Address Translation (NAT)
- Dynamic routing

****
## IDS and IPS

**Intrusion Detection System / Intrusion Prevention System**
- Watch network traffic

**Intrusions**
- Exploits against operating systems, applications, etc.
- Buffer overflows, cross-site scripting, other vulnerabilities.

**Detection vs Prevention**
- Detection = Alarm or Alert
- Prevention = Stop it before it gets into the network

****
## Load Balancer

**Distribute the load or balancing the load**
- Multiple servers
- Invisible to the end-user

**Large-scale implementations**
- Web server farms, database farms

**Fault tolerance**
- Server outages have no effect
- Very fast convergence

## Proxy

![[Pasted image 20260410213241.png]]

- Sites between the users and the external network

- Receivers the user request and send the request on their behalf (the proxy)

- Useful for caching information, access control, URL filtering, content scanning

- Application may need to know how to use the proxy (explicit)

- Some proxies are invisible (transparent)

## NAS vs SAN

![[Pasted image 20260410213910.png]]

**Network Attached Storage (NAS)**
- is a storage device connected to a network that lets users access **shared files and folders**.
- File level access - means you access **actual files/folders directly**.

**Storage Area Network (SAN)**
- is a specialized high-speed network that provides storage to servers **as if it were their own hard drive**.
- looks and feels like a local storage device
- Block level access - means the storage gives raw chunks/blocks of disk space to the computer.
- Very efficient reading and writing

**Both requires a lot of bandwidth**
- May use an isolated network and high speed network technologies

## Access Point (AP)

![[Pasted image 20260410215407.png]]

it is a device that allows **wireless devices** to connect to a **wired network** using **Wi-Fi**.

![[Pasted image 20260410215542.png]]

**An access point is a bridge**
- Extends the wired network onto wireless network
- OSI layer 2 device

### Wireless networks is everywhere

**Wireless networking is pervasive**
- in many businesses they have many access points

**Your access points may not even be in the same building**
- One (or more) at every remote site

**Configurations may change at any moment**
- Access policy, security policies, AP configs

**The network should be invisible to your users**
- Seamless network access, regardless of role

## Wireless LAN controllers


![[Pasted image 20260410220631.png]]

- is a device/software that **centrally manages multiple wireless access points (APs)** in a network.
- Deploy new access points
- Performance and security Monitoring
- Configure and deploy changes to all sites
- Report on access point use
- Usually a propriety system
	- the wireless controller is paired with the  same manifacturer of access points
