## Variables
****

Are temporary containers that can hold different types of data such as text, numbers, collections, objects, and etc.

Variables can be named for easy read/write access by the programmer it is called an identifier.

****

## Identifiers
****

Variable name that has been set by the programmer. (IDENTIFIER RULES)

****

1. Identifier must be UNIQUE
2. Identifiers are CASE SENSITIVE
3. RESERVE KEYWORDS are NOT allowed as Identifiers
4. Identifier MUST start with a LETTER, $ or __
5. Identifiers CANNOT contain SPECIAL CHARACTERS

****

## 4 Ways to Declaring Variable
****

	1. Automatically
1. Using `let`
2. Using `const
3. Using `var`

****

#### Automatically
****

Automatic variables automatically declare themselves.
```
x = 5;
y = 12.5;
z = "Hello World";
```

****


#### Using `let`
****

Uses the `let` keyword, it cannot be redeclared. It is preferred to be used by default when declaring variables.
```
let x = 5;
let y = 12.5;
let z = "Hello World";
```

note: the redeclared means, once na dineclare na yung `let x` bawal na sya ulit ideclare.

****


### Using `const`
****

Uses the `const` keyword, it cannot be redeclared and also these variables cannot be reassigned or changed.

```
const x = 5;
const y = 12.5;
const z = "Hello World";
```

note: the meaning of `const` is constant, in mathematics the value of constant cannot be changed.

****


### Using `var`
****

Uses the `var` keyword, it can be redeclared and should only be used when you want to support older browsers.

```
var x = 5;
var y = 12.5;
var z = "Hello World";
```

****


## Datatypes
****

The type of data that the variable is currently holding.

****

1. String - text
2. Number
3. Boolean - true or false
4. Undefined - ito yung variable na wala tayong inaassigned na value.
5. Null - variable na walang value.
6. Object 
7. Bigint
8. Symbol

#### Example how we declaire it

**String**
```

```

**Number**
```

```

**Boolean**
```
let isCoding = false;
```

**Undefined**
```

```

**Null**
```

```

## Concatenation
****

Joining two or more strings together.

****

```
"Hello" + "World"
"Answer" + 12
"Pi" + 3.14
```

****

**Concatenating strings with other data types will automatically convert them into their string counterparts**

```
let $pi = 3.14;
alert("The value of pi is " + $pi);
```
