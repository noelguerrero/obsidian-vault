
## Numbers
****
One of the datatypes in JavaScript, It maybe a whole number or a decimal.

These are two types of numbers in Javascript
- Integer - Whole Numbers
- Float - Decimal Numbers
****

## Convert String to Numbers
****

```
//Convert String to Integer
let num = parseInt(5);

//Convert String to Decimal
let pi = parseFloat("3.14");
```

****
Unsucessful conversions will result into a NaN (Not A Number) Value.


### `parseInt()`

**Example1:**
```
let num1 = '5'
let num2 = 5;

num1 = parseInt(num1); 
// or parseInt("5"); or any value inside of it.

alert(parseInt(num1) + num2);
```
![[Pasted image 20250611202441.png]]

**Example 2:**
```
let num1 = '5'
let num2 = 5;

alert(parseInt(num1) + num2);
```
![[Pasted image 20250611202441.png]]


**So what happens if the value of variable is a combination of letter and number?**

```
let num1 = 'noel5';
let num2 = 5;

num1 = parseInt(num1);
alert(num1 + num2);
```

![[Pasted image 20250611202955.png]]

**but `parseInt()` is also a function that can get the first number in a value. So if their is a number character in the string value, it will get it. And the whole value becomes that first number. ** 

```
let num1 = '534aasd797asd979';
let num2 = 5;

num1 = parseInt(num1);
alert(num1 + num2);
```
![[Pasted image 20250611204200.png]]
It will get the 534 in the num1 value.


**If we `parseInt()` the float string value, it becomes an integer.**

```
let num1 = '15.5';

num1 = parseInt(num1);
alert(num1);
```
![[Pasted image 20250611205022.png]]


### `parseFloat()`

**the `parseFloat()` and `parseInt()` is the same. but the difference is their value.**

```
let num1 = "1.5";
let num2 = 2.1

num1 = parseFloat(num1);
alert(num1 + num2);
```
![[Pasted image 20250611204631.png]]


**and also if their is a decimal number in front of string, it will get it.**

```
let num1 = "3.1qrqeq5.5";
let num2 = 2.1

num1 = parseFloat(num1);
alert(num1 + num2);
```
![[Pasted image 20250611204735.png]]


**but if we `parseFloat()` the integer value. it will retain the 15**

```
let num1 = "15";

num1 = parseFloat(num1);
alert(num1);
```
![[Pasted image 20250611205457.png]]
we expecting it to be 15.00, but it will retain the 15.

## Arithmetic Operators
****
**Operators that can perform mathematical equations on numbers.**
****

| Operator | Function            | Example |
| -------- | ------------------- | ------- |
| +        | Addition            | 5 + 5   |
| -        | Subtraction         | 5 - 5   |
| *        | Multiplication      | 5 * 5   |
| /        | Division            | 5 / 5   |
| **       | Exponent            | 5 ** 5  |
| %        | Modulus (Remainder) | 5 % 5   |

****
Operators can be applied to variables as well.



## Arithmetic Precedence
****
**PEMDAS is followed in the order of precedence.**
****
1. **P**arentheses
2. **E**xponent
3. **M**ultiplication
4. **D**ivision
5. **A**ddition
6. **S**ubtraction
****
So meaning kahit sa code sinusunod nito yung PEMDAS rule

**Example:**
```
let x = 5;
let y = 10;

console.log((x+y)/x);
```
