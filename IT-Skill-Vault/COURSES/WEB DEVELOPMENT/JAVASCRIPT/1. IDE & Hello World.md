## `<script>` Tag
the `<script>` tag allows us to write JavaScript code inside of our HTML File.
```
<script>
	console.log("Hello World");
</script>
```


## `console.log()`
This code displays a log in the developer console of browsers.
```
console.log("Hello World");
console.log("Hi");
```


## Developer Tools
is a useful tool in debugging JavaScript codes and also viewing our output using console.log()

## `document.getElementById()`
This code retrieves an element from our HTML using its ID and lest us manipulate its properties/attributes.
```
document.getElementById("someid");
```


## Script tag placement
```
<html>
	<head>
		<script>SCRIPT CODE HERE<script>
	</head>
	<body>
	
		CONTENT

		<script>SCRIPT CODE HERE<script>
	</body>
</html>
```

Usually the `<script>` tag that contains javascript code is place inside `<head>` tag or inside the `<body>` tag at the very bottom.


### Example code
```
<html>
	<head>
	    <script>
		    console.log("Hello World");
	    </script>
	</head>

	<body>
	</body>
</html>
```
Note: it doesn't matter if you add semicolon in the last part of the code, but for the best practices just add it.
![[Pasted image 20250525110613.png]]


**since the mobile browser does not have console, you can do this.**

```
<html>
	<head>
	</head>

	<body>
		<h1 id="someText"></h1>

		<script>
			document.getElementById("someText").innerHTML = "Hello World";
	    </script>
	</body>
</html>
```
**note:** 
- if we do something like this, that we manipulate a specific element tag, make sure that the JS code is in the very bottom, because if not, it does not work.
- Because the code is running sequencial, if we find the id "someText" when i doesn't declare yet, it won't work. So the specific element tag must declared first before we find it and change its value or manipulate it.

**Code explanation:**

`document` - this code refer the html document.

`.getElementById("someText")` - this code select a specific element throught id in this case we have an id value "someText", where in the id of the h1 tag in the body.

`.innerHTML` - this code use to change the content of a specific html element 

`= "Hello World;"` - this code is the assigned value of `.innerHTML`.
