
## ANCHOR ELEMENT

Indicates a hyperlink, this is used to link another page.

**SYNTAX:**

```
<a href = "file link or path">home</a>

EXAMPLES:

<a href = "https://www.youtube.com/SDPTSoluions">Sdpt solution</a>
<a href = "c/xampp/htdocs/POS management System">button</a>

```


## ELEMENT ATTRIBUTES

Provides additional information about the elements.

Every elements can have an attributes, some attributes are element specific and cannot be aplied to other elements, an element can also have multiple attributes.

**SYNTAX:**

```
<element attribute = "value">Content here</element>
```


## ANCHOR ELEMENT ATTRIBUTES

Common Attributes Used


| Attribute | Description                                                    |
| --------- | -------------------------------------------------------------- |
| href      | Indicates the url it will go to                                |
| target    | Indicates where the link will open example: it open in new tab |

All Attributes is on this website:

https://www.w3schools.com/tags/tag_a.asp


## HREF ATTRIBUTE

Can take a value of a URL or a file path

**EXAMPLES:**
```
<a href ="home.html">home</a>
<a href= "https://www.youtube.com">youtube</a>
```


## TARGET ATTRIBUTE

Takes _blank, _self, _parent, _top or iframe as value

**EXAMPLES:**
```
<a href = "home.html" target= "_blank">home</a>
<a href = "about.html" target= "_self">About</a>
```

Notes: yung  _blank is mapupunta sya sa new tab. And yung _self is mapupunta parin sya sa current tab or yung gamit. But by default nag oopen sya sa current tab or _self_.
