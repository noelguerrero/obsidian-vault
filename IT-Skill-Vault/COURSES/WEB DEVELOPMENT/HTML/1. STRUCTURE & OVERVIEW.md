
## HTML

 - HTML (Hyper Text Markup Language) is the standard language used to create webpages.
	 
 - HTML are composed of many elements, and these elements describe how the website should appear in the browser.

## HTML 5

We are curretly using HTML5 which is the current standard and still updated up to this day.

## ELEMENTS

describe how the website should appear in the browser

```
 Opening tag --> <e> Content </e>  <-- Closing tag
```
**note:** most of the element requires opening and closing tag. but there is some element that din't require.

## HTML PAGE STRUCTURE

The standard starting structure of an HTML

```
<!DOCTYPE html> <-- It indicates we are using html 5

<html> <-- It indicates that starts of our html document (opening tag)


<head> <-- Head element is used for the title, styling, scripts and other things              to be link in our HTML file 

    <title>Page title</title>
    
</head>


<body> <-- Body element contains the main content of our web page
	<p>Hello World</p>
</body>


</html> It indicates that ends of our html document (closing tag)
```


## FIRST HELLO WORLD USING HTML


```
<!DOCTYPE html>
```
