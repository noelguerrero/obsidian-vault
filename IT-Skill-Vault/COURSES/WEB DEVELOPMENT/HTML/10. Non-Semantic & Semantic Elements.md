## Non - Semantic Elements
Elements that have NO clear depiction of its content, it is typically an element with a generic tag name that contain anything.

## Class & ID Attributes
- Are used to identify elements
- Can be applied to any elements
- Are used to label non-semantic elements
- Used in styling or modifying elements

**ID** - Are used to identify a single element in our HTML Document, this can be used to change its design or modify and retrieve the element's values
```
<div id="main-container">
	<p>Lorem Ipsum</p>
</div>
```

PS: Same IDs should NOT be used on multiple elements.

**Class** - Are used to identify multiple elements in our HTML document, particularly repetitive elements that may also be used to change its design or modify and retrieve the element's values.
```
<div class="comment">
	<p>Comment 1</p>
</div>

<div class="comment">
	<p>Comment 2</p>
</div>
```

PS: Classes can be used on multiple elements.


## Semantic Elements
Elements that clearly describes what it contains, to both the developer and the browser. These are elements which have specific tag names.

It does not change any styling on the actual document. It is used to structure the website in a cleaner way.
