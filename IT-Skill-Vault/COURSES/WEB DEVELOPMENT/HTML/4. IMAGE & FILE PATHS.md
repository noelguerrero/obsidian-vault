
## A. IMAGE ELEMENT 

Indicates an image

```
Syntax:

<image src = "image.path" alt="image"/>

Example:

<image src="name.png" alt="image" width="200" height="200"/>
```

### IMAGE ELEMENT ATTRIBUTES

| ATTRIBUTE | DESCRIPTION                               |
| --------- | ----------------------------------------- |
| src       | Indicates the file path to load the image |
| width     | Indicates the width                       |
| height    | Indicates the height                      |
| alt       | Text show when image fails to load        |

All attributes:
https://www.w3school.com/tags/tag_img.asp

### SRC Attribute

Can take a value of a URL or a file path

```
Examples:

<img src="name.png"/>

<img src="https://www.w3school.com/image.png">
```


### WIDTH & HEIGHT ATTRIBUTE

Take a number in pixels or percentage

```
Examples:

<img src="imga.png" height="200" width="200">

<img src="imga.png" height="100%" width="80%">

If you only indicates one of the two, then the aspect ratio would be retained

Note: if value lang ang nakalagay like, 200 it indicates px. And if value with % like, 100% it indicates the percentage part of the screen.
```


### ALT ATTRIBUTE

Shows the text when the image failed to load.

```
Example:

<image src="image.png" alt="error"/>

```

## C. FILE PATHS

### FILE PATHS

Different level of file paths

| Value              | Description                                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| "name.png"         | The file is in the same folder.                                                                                                |
| "images/name.png"  | The file is in the folder: images in the current folder.                                                                       |
| "/images/name.png" | The file is in the folder: images at the root of the current web.                                                              |
| "../name.png"      | The file is in the folder one level up from the current folder (.. meaning nag back sya one level up from the current folder.) |
| Absolute Path      | The file's path is fully specified like url or complete path of a certain file.                                                |
