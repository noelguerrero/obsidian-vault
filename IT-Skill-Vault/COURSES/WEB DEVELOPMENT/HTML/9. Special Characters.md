## HTML Entities

Special Characters that are usually not accessible by the keyboard we instead use codes to display them in our HTML Document, It is also used to display reserved keyword from html like the "<" and ">" symbol

HTML entities are displayed using an ampersand "&" followed by an "entity name", "entity number" or "entity hexadecimal" and ending with semicolon ";"

## HTML Emoji

It looks like an icon but is actually a character, emojis are characters from the UTF-8 charset, Emojis are also entities so it is accessed as same as the other HTML Entities, although they don't have an "Entity Name"

Emojis are from the UTF-8 make sure that you are using the correct charset, for best compatibility.

**Using UTF-8 Encoding**
`<meta charset="UTF-8"/>`

## HTML Charsets

### ASCII
It is the first character encoding standard. ACII had 128 different characters that could be used; numbers (0-9), English letters (A-Z), and some special characters like !,$,+,-,(),@,<>.

### ISO-8859-1
It is the default character encodin of HTML 4 this character set had 256 characters.

### ANSI
It was the original windows character encoding it is same as the ISO-8859-1 but this has 32 more characters.


### UTF-8 (Unicode)
it is the modern standard of character encoding it support 1,112,064 characters this includes the symbols and emojis.
