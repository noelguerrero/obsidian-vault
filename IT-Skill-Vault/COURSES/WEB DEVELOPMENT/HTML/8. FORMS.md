
## `<form>` Form Element
Indicates a forms
```
<form action="/action_page.php" target="_blank">
	<input type="email"><br/>
	<input type="password"><br/>
	<input type="submit">
</form>
```

`<form>` tags are used in combination with other elements like `<input>`, `<textarea>` and `<select>`.



### Form Element Attributes

| Attribute | Description                                                         |
| --------- | ------------------------------------------------------------------- |
| action    | Specifies the action to perform after submitting the form           |
| method    | Specifies the type of method that the form will use "GET" or "POST" |
| target    | Specifies where ididisplay yung action sa new tab or sa current tab |



## `<input>` Element
Indicates a Textfield, Radiobutton, Checkbox etc.

```
<input type="text"/>
<input type="password"/>
<input type="radio"/>
<input type="checkbox"/>
<input type="range"/>
<input type="number"/>
<input type="date"/>
<input type="file">
```
`<input>` Tag has a lot of variety, we can change this by using the "type" attribute.




## `<input>` Element Attributes
General Attributes

| Attribute | Description                                                                  |
| --------- | ---------------------------------------------------------------------------- |
| type      | Specifies the type of input                                                  |
| name      | Specifies the name of the input (that will passed to server)                 |
| value     | Specifies the default value of the input (default value ng textbox if meron) |
| required  | Specifies that the field is required                                         |
| disable   | Specifies that the field is disable                                          |
| readonly  | Specifies that the field can only be read                                    |
**Example Code:**
```
<form action="">
     <p>Normal Input text</p>
     <input type="text"/> <br>
</form>


<form action="">

     <input type="text" disabled>
</form>


<form action="">
     <p>Input text with Default Value</p>
     <input type="text" value="default value here">
</form>


<form action="">
     <p>Readonly Input text</p>
     <input type="text" readonly value="Di ka pwede mag input dito">
</form>


 <form action="">
     <p>Required text input</p>

### `<input type="radio">` Attribute

| Attribute | Description                                                                                               |
| --------- | --------------------------------------------------------------------------------------------------------- |
| checked   | Specifies if the radio button is selected by default                                                      |
| name      | To group the radio button (para ma select mo yung ibang button at hindi ka mag lock sa isang button lang) |
PS: Radio button can be grouped by specifying different radio button with the same name attribute

EXAMPLE CODE:
```
<form action="">
    <p>RADIO BUTTON</p>
    <input type="radio" name="answer" id="true" checked>
    <label for="true">True</label>
    <br>
    <input type="radio" id="false" name="answer">
    <label for="false">false</label>
  </form>
```

![[Pasted image 20250307220742.png]]

Note: 
- Usually nag lolock ang radio button once na clinick so to prevent it use name attribute and make it the same in other radio button.
- By dafault the checked button is "true" since gumamit tayo ng checked attribute sa "true" radio button
- Then the label element sa baba is for label ng radio. Usually pag nilagyan mo ng normal na label ang radio, pag clinick mo yung text hindi magchechek yung button. So para mag maganda ang UX gumamit ka ng label attribute para pag clinick na user ang text, mag checheck ang radio button.

```

	</textarea>
</form>

## `<select>` Element
Indicates a drop-down list

```
<form>
	<select name="members">
		<option value="David">Noel</option>
		<option value="David">Jasper</option>
		<option value="David">Roie</option>
		<option value="David">Andrei</option>
		<option value="David">Dennis</option>
	</select>
</form>
```

PS: The `<select>` element is used in combination with the `<option>` element.


### `<select>` Element Attributes

| Attribute | Description                                                 |
| --------- | ----------------------------------------------------------- |
| multiple  | Specifies if the user can select multiple items in the list |
| size      | Specifies number of options visible on the drop-down        |
| name      | Specifies the name of the textarea (passed to server)       |
| required  | Specifies that the field is required                        |
| disable   | Specifies that the field is disabled                        |
| form      | Specifies that the form it belongs to using the form's id   |

## `<label>` Element
Indicates a label for an `<input>`, `<textarea>` and `<select>` element

```
<label for="txtFullName">Full Name:</label>
<input type="text id="txtFullName" name="fullName">

<br>

<label for="sex">Sex: </label>
<select>
	<option value="M">Male</option>
	<option value="F">Female</option>
</select>
```

PS: The `<label>` element "for" attribute uses an id value to indicate what element they are bound to.
