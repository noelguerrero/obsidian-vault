
## A. LIST TYPES

```
1. Uordered List <ul>
	* List without numbering
2. Ordered List <ol>
	* List with numbering
```


### < li > LIST ITEM ELEMENT

An item inside a list

```
	<li>C<li>
	<li>C++<li>
	<li>C#<li>

Note: <li> tags are used within <ol> or <ul> elements.
```

### LIST ITEM ATTRIBUTES

Common attributes used.


| Attribute | Description                                                                    |
| --------- | ------------------------------------------------------------------------------ |
| value     | Specifies the number value of the item (only for < li > within < ol > element) |

### < ul > UNORDERED LIST ELEMENT

List without numbering

**Example 1:**
```
<ul>
	<li>C<li>
	<li>C++<li>
	<li>C#<li>
	<li>Python<li>
	<li>Java<li>
</ul>
```

### < ol > ORDERED LIST ELEMENT

List with numbering

**Example 1:**
```
<ol>
	<li>A</li>
	<li>B</li>
	<li>C</li>
</ol>
```

**Output:**
![[Screenshot 2024-11-21 201738.png]]

**Example 2:**
```
<ol>
	<li value="10">A</li>
	<li>B</li>
	<li>C</li>
</ol>

Note: Meaning ng value="10", sa number 10 sya magiisatart magbilang.
```



**Output:**
![[Screenshot 2024-11-21 201712.png]]
