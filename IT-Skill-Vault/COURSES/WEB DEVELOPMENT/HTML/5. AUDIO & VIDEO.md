
## A. SOURCE ELEMENT 

Indicates files for the browser to choose from.

```
Example:

<source src="music.mp3" type="audio/mp3">

<source src="music.ogg" type="audio/ogg">

Note: Source tags are used within <audio>, <video>, and <picture> elements.

```

### SOURCE ELEMENT ATTRIBUTES

Common Attributes used

| Attribute | Description                            |
| --------- | -------------------------------------- |
| src       | Indicates the file path                |
| type      | Indicates the MIME-type of the resouce |
**All Attributes:**
**visit:** w3schools.com for more info.

### SRC ATTRIBUTE

can take a value of a URL or a File path

```
<source src="music.mp3">

<source src="music.ogg">
```


### TYPE ATTRIBUTE

Specifies the MIME-Type of the source

```
<source src="vid.mp4" type="video/mp4">

<source src="vid.ogg" type="video/ogg">
```

MIME-Type helps in identifying file types so it can be handled accordingly.

**MIME-Type List:**
https://www.freeformatter.com/mime-types-list.html


## B. AUDIO ELEMENT

Used to play audio files.

```
Example 1:

<audio controls>
	<source src="music.mp3" type="audio/mp3">
	<source src="music.ogg" type="audio/ogg">
	Browser doesn't support the audio tag.
</audio>

Sa example 1 meron tayong 2 choices of files, kapag hindi gumana ang mp3 type may choice pa sya na ogg, then pag hindi naman gumana yung dalawa lalabas yung Browser doesn't support.... na nakalagay sa baba

Example 2:

<audio src="music.mp3" controls>
	Browser doesn't support the audio tag
</audio>

Sa example 2 naman mas risky since pag hindi gumana yung mp3, automatic ang lalabas lang ay yung Browser doesn't support....

Note: ibigsabihin ng controls attribute, i shoshow nyo lang yung controls yung pause, play, and etc. But by default naka hide lang yung controls.
```


### AUDIO ELEMENT ATTRIBUTES

Common Attributes Used

| Attribute | Description                                                           |
| --------- | --------------------------------------------------------------------- |
| src       | Indicates the file path.                                              |
| controls  | Shows controls like play, pause.                                      |
| autoplay  | Play audio automatically when loaded (doesn't work on some browsers). |
| muted     | The audio would be muted by default.                                  |
| loop      | Makes the audio replay infinite times.                                |

**All Attributes:**
**visit:** w3schools.com for more info.


### SRC ATTRIBUTE

Can take a value of a URL of a File Path.

```
Example:

<source src="audio.mp3"/>
```

### OTHER ATTRIBUTES

Some attributes doesn't need any value

```
Example:

<audio src="audio.mp3" controls autoplay loob muted />
```

## C. VIDEO ELEMENT

Used to play video files.

```
Example 1: long method

<video width="320" height="240" controls>
	<source src="vid.mp4" type="audio/mp4">
	<source src="vid.ogg" type="audio/ogg">
	//Text message if files not working
	Browser doesn't support the video tag
</video>
```

Sa example 1 is the long method tulad ng format sa audio may another choice din ito once na nag error yung unang file.

```
Example 2: short method

<video src="vid.mp4" width="320" height="240" controls>
	Browser doesn't support the video tag. 
</video>
```

Also like sa audio ang example 2 is the short method, and disadvantage nito wala siyang other choice once na nag error yung source file.

### VIDEO ELEMENT ATTRIBUTES

Common attribute used.

| Attribute | Description                                                           |
| --------- | --------------------------------------------------------------------- |
| src       | Indicates the file path.                                              |
| controls  | Shows controls like play, pause.                                      |
| autoplay  | Play audio automatically when loaded (doesn't work on some browsers). |
| muted     | The audio would be muted by default.                                  |
| loop      | Makes the audio replay infinite times.                                |
| width     | Sets the width of the video player                                    |
| height    | Sets the height of the video player                                   |
**All Attributes:**
**visit:** w3schools.com for more info.

### EXAMPLE CODE:

```
<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Document</title>

</head>

<body>

    <h2>Example 1 (na naka loop)</h2>

   <!--LONG METHOD-->

   <video controls loop width="500" height="500">

        <source src="testingVideo.mp4" type="video/mp4"/>

        Audio Error.....

   </video>

  

   <br>

  

   <h2>Example 2 (naka muted sa umpisa)</h2>

   <!--SHORT METHOD-->

	<video src="testingVideo.mp4" type="video/mp4" controls muted width="500" height="500">

        Error...

   </video>

  
  

</body>

</html>
```
