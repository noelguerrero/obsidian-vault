
## A.  < table > TABLE ELEMENT

Indicates a table

**Example:**
```


<table>
	<tr>
		<th>TITLE 1</th>
		<th>TITLE 2</th>
	</tr>

	<tr>
		<td>Content 1</td>
		<td>Content 2</td>
	</tr>
</table>
```

**Output:**

| TITLE 1   | TITLE 2   |
| --------- | --------- |
| Content 1 | Content 2 |

Note: < table > tags are used in combination with other elements like table row < tr >, table header < th >, table data < td >, and etc  
Note: yung actual output walang border, so need mo pa gumamit ng css para malagyan ng border.

### < tr > TABLE ROW ELEMENT

Indicates a table row

**Example:**
```


<table>
	<tr> <-- table row 1
		<th>Row 1</th>		
	</tr>

	<tr> <-- table row 2
		<td>Row 2</td>
	</tr>
</table>
```

**Output:**

| Row 1 |
| ----- |
| Row 2 |

Note: < tr > Tags are used within the < table > tag to indicate a row in the table.
Note: yung actual output walang border, so need mo pa gumamit ng css para malagyan ng border.

### < th > Table Heading Element

Indicates a table cell (Heading)

```
<table>
	<tr> 
		<th>Column 1</th> <-- Table heading
		<th>Column 2</th> <-- Table heading
	</tr>

</table>
```

**Output:**

| Column 1 | Column 2 |
| -------- | -------- |

Note: < th > Tags are used within the < tr > tag to indicates a heading cell.
Note: yung actual output walang border, so need mo pa gumamit ng css para malagyan ng border.

### < td > Table Data Element

Indicates a table cell (content)

```
<table>
	<tr>
		<th>Heading 1</th>
		<th>Heading 2</th>
	</tr>

	<tr>
		<td>Content 1</td> <-- table data
		<td>Content 2</td> <-- table data
	</tr>
</table>
```

Output:

| Heading 1 | Heading 2 |
| --------- | --------- |
| Content 1 | Content 2 |

Note: < td > Tags are used within < tr > tag to indicate a content cell or table data.
Note: yung actual output walang border, so need mo pa gumamit ng css para malagyan ng border.


### `<th>` & `<td>` Attributes
Common Attributes Used


| Attribute | Description                                    |
| --------- | ---------------------------------------------- |
| colpan    | Specifies the column span (sakop) of the cell. |
| rowspan   | Specifies the row span (sakop) of the cell.    |

 Note: you can se all the td and th attributes in w3school website.

Example Code:
```
<table>
     <tr>
          <th rowspan="2">Name</th>
          <th colspan="2">Subject</th>
     </tr>
     <tr>
          <td>C++</td>
          <td>Java</td>
     </tr>
     <tr>
          <td>Noel</td>
          <td>91</td>
          <td>90</td>
     </tr>
    </table>
```

### `<caption>` Caption Element
Indicates a caption

```
<table>
	<caption>Caption Here</caption>
	<tr>
		<th>title 1</th>
		<th>Title 2</th>
	</tr>
	
	<tr>
		<td>Content 1</td>
		<td>Contnet 2</td>
	</tr>
</table>
```
`<caption>` tags by default are centered aligned and on the top of the table, it can e customized using CSS.

Example Code:
```
<table>
     <caption>First Sem Grade</caption>
     <tr>
          <th rowspan="2">Name</th>
          <th colspan="2">Subject</th>
     </tr>
     <tr>
          <td>C++</td>
          <td>Java</td>
     </tr>
     <tr>
          <td>Noel</td>
          <td>91</td>
          <td>90</td>
     </tr>
    </table>
```

### Other table tags

| Element      | Description                                                               |
| ------------ | ------------------------------------------------------------------------- |
| `<colgroup>` | Specifies a group of one or more columns in a table for formatting        |
| `<col>`      | Specifies column properties for each column within a `<colgroup>` element |
| `<thead>`    | Groups the header content in a table                                      |
| `<tbody>`    | Groups the body content in a table                                        |
| `<tfoot>`    | Groups the footer content in a table                                      |
Example of execution of thead, tbody
```
<table>
     <caption>First Sem Grade</caption>
     <thead> <-- thead
     <tr>
          <th rowspan="2">Name</th>
          <th colspan="2">Subject</th>
     </tr>
     </thead>

	<tbody> <-- tbody
     <tr>
          <td>C++</td>
          <td>Java</td>
     </tr>
     <tr>
          <td>Noel</td>
          <td>91</td>
          <td>90</td>
     </tr>
     <tbody> 
    </table>
```
