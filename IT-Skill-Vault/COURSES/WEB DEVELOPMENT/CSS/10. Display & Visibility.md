
## CSS Display
Indicates the display behavior of an element.

Example Syntax:
```
p{
	display: block;
}

span{
	display: incline;
}
```
note:
- the default display value of paragraph tag is block, while the span is incline.

### Common CSS Displays
![[Pasted image 20250522121347.png]]

**Display block Example:**
HTML
```
<p>Hello</p>
<p>World</p>
```

CSS
```
p{
   background-color: red;
   display: block;
}
```
![[Pasted image 20250522121954.png]]
Note: the display block takes the full width of the element or whole space, and when we create a new element it goes in next line. 

FYI: the default value of the p element is also block, and also the background color show you how display block occupied the space.


**Display incline example:**
HTML:
```
<span class="span1">Hello</span>
<span class="span2">World</span>
```

CSS
```
.span1{
   background-color: red;
   display: inline;
}

.span2{
   background-color: yellow;
   display: inline; 
}
```
![[Pasted image 20250522122639.png]]
As you can see the display inline only takes the full width of the content not the whole element, and when we create a new element it goes next to it.

note: the default value of span is inline.


**Display none example:**
Html:
```
  <p class="p1">Hello</p>
  <h1>Hide Me</h1>
  <p class="p2">World</p>
```
css:
```
.p1{
   background-color: red;
   display: block;
}

h1{
   display: none;
}

.p2{
   background-color: yellow;
   display: block;
}
```

**Example:**
```
.in{
   background-color: red;
   display: inline;
}  

.in-b{
   background-color: yellow;
   display: inline-block;
   width: 500px;
}
```
![[20250522-0445-14.3891034.mp4]]
The difference of inline and inline block, the inline only takes only the space of the content and it not takes the inputs(configuration of spacing), while the in-block also takes only the space of the content, but if it have a inputs (spacing configurations) like in the video, it respect it and include it. 

note: the inline is immovable, while the inline-block you can still change the margin, padding and other spacing.


**Practical Example:**
Html
```
  <div class="container">
    <h1>1</h1>
  </div>
 
  <div class="container">
    <h1>2</h1>
  </div>
```

CSS
```
.container{
   height: 100px;
   width: 100px;
   background-color: tomato;
   display: inline-block;
} 

h1{
   text-align: center;
}
```

![[Pasted image 20250522125623.png]]
As you can see we didn't use the incline because we use a width and height property (so we have a configuration of spacing) and the inline didn't takes it, remember it only cares about the spacing of the content not the inputs.




## CSS Visibility
Indicates the visibility of an element

Elements will always take up space in the layout. although if we decrease the visibility it.

**Syntax and values:**

hidden
```
selector{
	visibility: hidden;
}
```

Visible (default value)
```
selector{
	visibility: visible;
}
```

![[Pasted image 20250522130751.png]]


**Example:**

Html
```
<body>
  <div id="one" class="container">
    <h1>1</h1>
  </div>  

  <div id="two" class="container">
    <h1>2</h1>
  </div> 

   <div id="three" class="container">
    <h1>3</h1>
  </div>

  <div id="four" class="container">
    <h1>4</h1>
  </div>
  
   <div id="five" class="container">
    <h1>5</h1>
  </div>

</body>
```

CSS:
```
.container{
   height: 100px;
   width: 100px;
   background-color: tomato;
   display: inline-block;
}

h1{
   text-align: center;
}

#three{
   visibility: hidden;
}
```
