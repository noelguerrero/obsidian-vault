## CSS Units
- These are used in sizes on CSS, such as the 'font-size', 'width', and 'height'
**We have 2 categories of Units**
- Absolute Lengths
- Relative Lengths

### Absolute Lengths
- absolute length means hindi sta mababago at wala siyang pinagbabasehan.

#### Most used relative length in font (em and rem)

##### em:
first we talk about the parent and child tag when we use the relative lengths
example:

**Html:**
```
<body> <-- parent tag
	<h1>Text<h1> <- Child Tag
</body>
```

**CSS**
```
body{ 
	font-size 24px; <-- the parent tag font size
}

h1{
	font-size 5em; <-- the parent tag font size
}
```

So ang mangyayari dito yung 5em na size i mumuiltiply sa font size ng parent tag magiging: 5x24 = 120

![[Pasted image 20250514183231.png]]
so basically ang em ay nag babase sa parent tag.

##### rem
and the rem is like em but naka base sya sa root (like the html tag).


#### How about the containers

**Absolute length**
HTML:
```	
<body>
  <div class="box">
  </div>
</body>
```
CSS:
```
.box{
    width: 500px;
    height: 500px;
    background-color: red;
}
```

![[Screen Recording 2025-05-14 184925.mp4]]


**Relative Length**
HTML:
```
<body>
  <div class="box">
  </div>
</body>
```
CSS:
```
.box{
    width: 30vw;
    height: 50vh;
    background-color: red;
}
```
pwede ring
```
.box{
    width: 30%;
    height: 50%;
    background-color: red;
}
```
![[Screen Recording 2025-05-14 185401.mp4]]


**So basically yung mga absolute lengths (like px and pt) is naka fix na yung size nila kahit na magpalit ka ng screen size, mananatili parin yung size ng isang element. And yung relative length (like rem, em, vm, vh) is dumepedende sila sa size root, parent tag and viewport**
