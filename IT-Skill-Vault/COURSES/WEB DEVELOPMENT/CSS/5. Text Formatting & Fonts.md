## Text Alignment
![[Pasted image 20250517115232.png]]

**properties and values of text-align**
```
.left{
	text-align: left; 
}

.right{
	text-align: right; 
}

.center{
	text-align: center; 
}

.justify{
	text-align: justify; 
}
```


**properties and values of text-align-last**
```
.left{
	text-align-last: left; 
}

.right{
	text-align-last: right; 
}

.center{
	text-align-last: center; 
}

.justify{
	text-align-last: justify; 
}
```

note: text-align-last -> is yung last line of text lang yung mababago
**example:**
`text-align-last: right;`

**White Space** -> kung ano yung magiging behavior ng text kapag sumobra na sa screen.

No Wrap
```

	white-space:normal;
}
```
![[Pasted image 20250517123123.png]]


Normal
```

	white-space: normal;
}
```
![[Pasted image 20250517123141.png]]


Pre
```

	white-space: pre;
}
```
![[Pasted image 20250517123223.png]]

note: the pre wrap is same as nowrap but the difference is sumusinod it sa pag ka stucture sakanya

example:
```
<p>noel 
	guerrero</p>
```

output:
```
noel 
	guerrero
```

## Custom Google Fonts
We can add more fonts to our website by importing from google fonts.

### 2 ways to import google font
1. Using the `<link>` tag on HTML
2. Using `@import` on CSS
