## Box Shadow
Creates a shadow around an element. This gives a 3D feeling in our design.

### First way to use box shadow
most easiest way of adding a box shadow
```
.container{
	box-shadow: 3px 5px black;
}
```
**Parameter Guide**  `box-shadow: x-off y-off color;`
x-offset -> left (negative value) and right (positive value)
y-offset -> Top (negative value) and bottom (positive value)
color -> color

**Example:**
html:
```
<div class="container">
<div>
```
css:
```
.container{
   height: 100px;
   width: 300px;
   box-shadow: 5px 5px black;
   border: 1px solid black;
}
```

#### Blur property
You can specify a blur on our box shadow
```
.container{
   box-shadow: 5px 5px 10px black;
}
```
**Parameter guide** `box-shadow: x-offset y-offset blur color;`

note: 
- the higher the blur value the higher the blur of box shadow is.
- the parameter must in order, except for the color.

**Example:**
```
.container{
   height: 100px;
   width: 300px;
   box-shadow: 5px 5px 10px black;
   border: 1px solid black;
}
```
![[Pasted image 20250520210304.png]]
note:
- you can use other color methods as well like: rgb, rgb and so on.
- And also other units as well like (percent, em, rem and so on).


#### Spread Property
You can also specify a spread on our box shadow. (yung kapal nung shadow)

**example syntax:**
```
.container{
	box-shadow: 5px 5px 10px 3px black;
}
```
**parameter Guide** `box-shadow: x-offset y-offset blur spread color;`

**Example:**
```
.container{
   height: 100px;
   width: 300px;
   box-shadow: 5px 5px 10px 5px rgba(0,0,0,0.9);
   border: 1px solid black;
}
```

#### Inset Property
Add an inset to the box shadow to invert the shadow (magiging nasaloob yung shadow instead na nasa labas).

**Example syntax:**
```
.container{
	box-shadow: 5px 5px 10px 3px black inset;
}
```
**parameter Guide** `box-shadow: x-offset y-offset blur spread color inset;`

**Example:**
```
.container{
   height: 100px;
   width: 300px;
   box-shadow: 5px 5px 10px 5px rgba(0,0,0,0.9) inset;
   border: 1px solid black;
}
```

### Multiple box shadow
Create multiple box shadows in one element.

**Example syntax:**
```
.container{
	box-shadow: 2px 2px 10px 3px black, -2px -2px 10px 3px blue;
}
```
note: same parameters, nag add lang tayo ng isang box shadow

**Example:**
```
.container{
   height: 100px;
   width: 300px;
   box-shadow: 5px 5px 10px 5px rgba(0,0,0,0.9), -5px -5px 10px 5px blue;
   border: 1px solid black;
}
```
