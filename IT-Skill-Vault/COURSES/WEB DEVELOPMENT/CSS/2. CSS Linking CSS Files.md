
## Internal CSS
- CSS that use the `<style>` tag inside the head tag in HTML document
- This type is linking does not need any `.css` files. The `<style>` tag handles the styling of the current HTML file.

![[Pasted image 20250510130841.png]]



## External CSS
- Requires a seperate CSS files and makes use of the `<link>` tag for us to able to link the CSS file in our HTML Document.
- This type of linking is advantageous since we can reuse our CSS File over and over without retyping anything.

![[Pasted image 20250510131651.png]]

note: the `rel` attribute indicates the relationship (a 'stylesheet') between the html document and the `style.css` file in the `href` attribute.



## Inline CSS
- This is the fastest way to integrate styles to our HTML Document
- This can also make your code very hard to read so don't use it inless you really need to.
- It uses the style attribute in all the elements.
