## Sidebar with Navbar
**Html:**
```
<body>
    <nav class="sidebar">
        <div class="brand-container">
            <img class="logo" src="img.png" alt="logo">
            <h2 class="brand-title">Lorem Ipsum</h2>
        </div>

        <div class="links-container">
            <a class="link" href="#">Dashboard</a>
            <a class="link" href="#">Students</a>
            <a class="link" href="#">Faculty</a>
        </div>
        <h4 class="message">Hi, Noel Guerrero</h4>
    </nav>

    <nav class="navbar">
        <div class="tools-container">
            <a class="tool1" href="#">Tool1</a>
            <a class="tool2" href="#">Tool1</a>
            <a class="tool3" href="#">Tool1</a>
            <a class="tool4" href="#">Tool1</a>
        </div>    
    </nav>

    <main class="main-content">
        <h1>Content Here</h1>
    </main>
</body>
```
