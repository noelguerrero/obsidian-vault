## Background Color
#### Color Can be set using:
- **Color Names** (predefined)
- **RGB** (Red, Green, Blue)
- **RGBA** (Red, Green, Blue, Alpha)
- **HSL** (Hue, Saturation, Lightness)
- **HSLA** (Hue, Saturation, Lightness, Alpha)
- **HEX**

**Background Color**
```
body{
	background-color: tomato;
}
```





## Background Image
Syntax:
```
body{
	background-image: url('liz.jpg');
}
```





## Background Repeat

**Repeat** - i rerepeat yung image para ma occipied lahat ng space (this is the default)
```
.body{
	background-image: url('liz.jpg');
	background-repeat: repeat;
}
```
![[Pasted image 20250518123011.png]]
note: by default pag hindi na occipied ng image ang isang element, i rerepeat nya ito.

**Repeat by in X axis** - i rerepeat nya yung image horizontally
```
.body{
	background-image: url('liz.jpg');
	background-repeat: repeat-x;
}
```

**Repeat by in Y axis**  - irerepeat nya yung image vertically
```

}
```

## Background Position
this is the property that configure the position of background

**Syntax:**
```
selector{
	background-position: x-pos y-pos;
}
```
x-pos - is the x axis position or horizntal position
y-pos - is the y axisposition or vertical

**example:**
```
body{
	background-image: url(img.png);
	background-position: right top;
}
```
the value of first parameter can be right, left, and center.
the value of second parameter can be top, center, bottom

**other way**:
```
body{
	background-image: url(img.png);
	background-position: 50% 50%;
}
```

**Example2**
```
body{
   background-image: url('liz.jpg');
   background-attachment: scroll;
   background-repeat: no-repeat;
   background-position: center -10%;
}
```
![[Screenshot 2025-05-19 181633.png]]

note: pwede rin paghaluin yung pre-define and percentage value. And also di lang pre defined and percentage ang pwede gamitin pwede rin yung pixels and other units.




## Background Size
Ito yung css property na ginagamit sa pag adjust ng background.

**syntax:**
```
selector{
	background-size: value; <-- it can be (auto, contain, cover)
}
```


**Auto**
```
body{
	background-image: url('liz.jpg');
	background-repeat: no-repeat;
	background-size: auto;
}
```
![[Pasted image 20250519182833.png]]
naka auto lang yung background natin. <- this is the default value.


**contain**
```
body{
	background-image: url('img.jpg');
	background-repeat: no-repeat;
	background-size: contain;
}
```
![[Pasted image 20250519184716.png]]
pipilitin nyang pagkasyahin yung background sa viewport natin habang pinapanatili yung aspec ratio.


**cover**
```
body{
	background-image: url('liz.jpg');
	background-repeat: no-repeat;
	background-size: cover;
}
```
![[Pasted image 20250519183053.png]]
icocover nya yung background natin kahit na izoom in or out.


**manual**
```
body{
	background-image: url('liz.jpg');
	background-repeat: no-repeat;
	background-size: 500px 300px;
}
```
note: 
- the first parameter is for X axis (horizontal), and the second parameter for Y axis (vertical).
- also pwede din gamitin yung ibang units.

Manual adjustment ng size ng background



## Backgroung short hand
it is a technique para mapagsamasama lahat ng configuration and to minimize the code into a one line

**example:**
```
body{
	background: url('liz.jpg') fixed no-repeat center top / auto
}
```
note: the order does not matter, Except for background position and size
