
## CSS Pseudo Classes
Adds style to special states of an element such as hover, click, disabled and etc. 

![[Pasted image 20250520121426.png]]

#### CSS Pseudo Class Example
We can use pseudo classes by adding it after a selector

```
button{
	backgorund-color: tomato;
}

button:hover{
	backgorund-color: red;
}

button:active{
	background-color:blue
}
```


**Example using a hover and active pseudo classes:**
```
.button{
   background-color: tomato;
   padding: 1%;
   color: black
}
 
.button:hover{
   background-color: red;
}

.button:active{
   background-color: blue;
}
```
![[20250520-0428-25.3272862.mp4]]


**Exampl using a disable pseudo classes**:
HTML
```
<button disabled>Click Me</button>
```
CSS
```
button{
   background-color: tomato;
   padding: 1%;
   color: black;
}

button:disabled{
   opacity: 0.5;
}
```

html:
```

```

## CSS Transitions
Adds a smooth transition in between style changes.

**Example:**
```
button{
	background-color: white;
	transition: 2s; <--
}

button:hover{
	background-color: red;
}

button:active{
	background-color: blue;
}
```
note: pwede i lagay ang transition sa pseudo class para ma configure yung pag transition nito, but mas recommended na nasa main class  or element ito ilalagay.
![[20250520-0502-28.6995190.mp4]]


**Example 2**
```
button{
   background-color: white;
   transition: 2s;
   width: 100px;
} 

button:hover{
   background-color: red;
   width: 200px;
}
```
![[20250520-0523-18.3932717.mp4]]
note: 
- kaylangan bago mag transition sa ibang style kaylangan may starting style sya,

- Tulad ng ipinakita sa video smooth ang transition dahil may naka declaire na starting value na  100px sa button class and  end value 200px sa hover class. At kapag walang naka declair na starting value hindi magiging smooth ang transition.


### Second way of using transition
Provide specific properties for smooth transition

**Example Syntax**
```
button{
	/* transition: property duration; */
	background-color: tomato;
	transition: scale 2s;
}
```
note: the first parameter of transition is property or the name of transition, and the second is the duration.
```
button{
	background-color: red;
	scale 1.1;
}
```


**Example for the width transition:**
```
button{
   background-color: white;
   width: 100px;
   transition: width 2s;
}

button:hover{
   background-color: red;
   width: 200px;
}
```
![[20250520-0536-37.8546075.mp4]]
Note: Dito diniclair natin yung specific property and duration na pag tratransition natin, notice na nung niremove natin yung **background-color** sa **transition** property, naging instant yung pag transition nya.


### Third way of using transition
Provide delays for the transition.

Example Syntax:
```
button{
	/* transition: duration delay; */
	background-color: white;
	width: 100px
	transition: 2s 2s; 	
}

button:hover{
	background-color: red;
	width: 200px
}
```

note: 
- the transition first parameter is duration of transition, and the second parameter is the delay.
- the parameter must be in order

### Forth way of using transition
Provide timing-function for the transition

**Example syntax:**
```
button{
	/* transition: timing duration */
	background-color: tomato;
	transition: linear 2s;
}

button:hover{
	background-color: red;
	scale:1.1;
}
```
note:
- the first parameter of transition is timing, and the second one is the duration.
- **timing function** - kung pano yung magiging itsura nung animation (mabilis ba sa una, mabagal ba sa una and so on).![[Pasted image 20250520140241.png]]

**Example:**
```
/* Ease */
.btn1{
   background: white;
   width: 100px;
   transition: ease 1s;
}
  
.btn1:hover{
   background-color: blue;
   width: 200px;
}

  
/* Linear */
.btn2{
   background-color: white;
   width: 100px;
   transition: linear 1s;
}
 
.btn2:hover{
   background-color: red;
   width: 200px;
}

  
/* Ease-In */
.btn3{
   background-color: white;
   width: 100px;
   transition: ease-in 1s;
}

.btn3:hover{
   background-color: green;
   width: 200px;
}

  
/* Ease-Out */
.btn4{
   background-color: white;
   width: 100px;
   transition: ease-out 1s;

}

.btn4:hover{
	background-color: yellow;
	width: 200px;
}

  
/* Ease-In-Out */
.btn5{
   background-color: white;
   width: 100px;
   transition: ease-in-out 1s;
}

.btn5:hover{
   background-color: orange;
   width: 200px;
}
```

### fifth way of using transition
Shorthand technique for transition.

**Example syntax:**
```
/* transition: property duration timing delay */
button{
	background-color: white;
	transition: scale 1s linear 2s;
}

button:hover{
	background-color: red;
	scale: 1.1;
}
```
**parameter guide:**  `transition: property duration timing delay`

Example:
```
.btn{
   background-color: white;
   width: 100px;
   transition: width 1s linear 0.2s, background-color 1s linear 0.2s;
}  

.btn:hover{
   background-color: blue;
   width: 200px;
}
```
![[20250520-1204-37.8737278.mp4]]
Note: 
- In this example naglagay tayo ng dalawang transition property (width, background-color) namay sariling duration, timing, delay. 
- Pwede rin namang isa lang, it depends sa specific na gusto natin mag transition.
- all the parameter order does not matter except for the duration and delay parameter.
