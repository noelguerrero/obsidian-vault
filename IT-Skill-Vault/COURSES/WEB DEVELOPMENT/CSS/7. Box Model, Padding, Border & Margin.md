## Box Model
![[Pasted image 20250519204254.png]]
note: Kada element may box model

**content** - Anything inside an Element can be considered a content.
**padding** - invisible spacing from the inside.
**border** - by the words itself it is a border (like in excel, ms word, and etc).
**margin** - spacing from the outside.


## Padding
it is an invisible space between the content and the border (or space from the inside).

**Note: meron syntax na `padding: auto;` ** nakung saan automatic na pinapantay nya padding ng top and bottom, left and right, or all sides



**Syntax 1:**
```
p{
	padding: 10px 10px;
}
```
padding: y-padding  x-padding

**Syntax 2:**
```
p{
	padding: 5px 10px 5px 10px;
}
```
padding: top right bottom left

**Syntax 3:**
```
p{
	padding-top: 5px;
	padding-right: 10px;
	padding-bottom: 5px;
	padding-left: 10px;
}
```
Note: you can use other units as well.

**Syntax: 4**
```
p{
	padding 25px;
}
```
padding: for all side (Top, bottom, left, and right)

Example:
```
p{
   background-color: tomato;
   margin: 10px;
   border: solid black;
   padding: 5px 10px 5px 10px;
}
```

## Border
A visibile line that separates the content and other elements.

Syntax:
```
selector{
	border: width style color;
}
```
note: the order does not matter.

**Different Styles of border:**
![[Pasted image 20250520102255.png]]

**Example:**
```
p{
	border: 2px solid black;
}
```


### Border Controls
Borders can be style differently on each side
```
div{
	border-top: 2px solid black;
	border-right: 2px dotted black;
	border-bottom: 2px solid black;
	border-left: 2px dotted black;
}
```

**Example:**
```
p{
   background-color: tomato;
   margin: 10px;
   border-top: 2px solid black;
   border-right: 2px dotted blue;
   border-bottom: 2px solid black;
   border-left: 2px dotted blue;
   padding: 5px 10px 5px 10px;
}
```
![[Pasted image 20250520103020.png]]


### Border Radius
Borders can become rounded to achieve a modern feeling
```
div{
	border: 2px solid black
	border-radius: 20px;
}
```

Example:
```
p{
   background-color: tomato;
   margin: 10px;
   padding: 5px 10px 5px 10px;
   border: 2px solid black;
   border-radius: 20px;
}
```

## Margin
It is an invisible space between the border and other elements.

**Note: meron syntax na `margin: auto;` ** nakung saan automatic na pinapantay nya yung margin top and bottom, left and right, or all sides.


**Syntax 1:**
```
div{
	margin-top: 10px;
	margin-right: 10px;
	margin-bottom: 10px;
	margin-left: 10px;
}
```

**Syntax: 2:**
```
div{
	margin: 10px 25px;
}
```
margin: y-margin x-margin

**Syntax 3:**
```
div{
	margin: 5px 10px 5px 10px;
}
```
margin: top right bottom left 

**Syntax 4:**
```
div{
	margin: 25px;
}
```
margin: all sides (top, bottom, left, and right)


**Example:**
```
body{
   margin: 0;
} 

p{
   background-color: tomato;
   padding: 5px 10px 5px 10px;
   border: 2px solid black;
   border-radius: 20px;
   margin: 5px 10px 5px 10px;
}
```
