
## Cascading Style Sheet (CSS)
- is the standard languange used to style an HTML Document
- it determines how to display the HTML Document in a more appealing way. Adding colors, formatting etc.

## CSS 3
We are currently using CSS3 which is the current standard and still updated up to this day.


## Text Editor
- We can use any text editor to create CSS files.
- Some text editor are specially made for coding that incorporates guides for a certain language like CSS.

example: Notepad, Notpad++, and Visual Studio Code


## CSS FIles
- This files could be linked to an HTML file and edited on text editors
- CSS extention: `.css`
PS: CSS can also be contained within the HTML file

## `<style>` Tag
- Used to integrate a Stylesheet (CSS) to our HTML Document without creating an external CSS File.
- The `<style>` tag contains CSS code that styles the current HTML Document it is attached to.
