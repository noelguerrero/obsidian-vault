## CSS Positions
It indicates the position behavior of an element.

Example Syntax:

Static <-- the default
```
selector{
	position: static;
}
```

Sticky
```
selector{
	position: sticky;
	top: 0;
}
```

## CSS Positioning Properties
It indicates the margin edges of a positioned elements.

note: "This does not work with static positioned elements".

![[Pasted image 20250522194904.png]]

**Example how to use it.**
```
.action-button{
	position: fixed;
	bottom: 10px;
	right: 10px
}
```


### Example how we use positions

Note: Di ko na ninotes yung static kasi yun yung default value ng position.
#### Fixed Position
```
h1{
   background-color: blue;
   position: fixed;
}
```
![[20250522-1158-15.0777063.mp4]]
Naka fixed lang sya sa isang position kahit na nag iiscroll tayo

**Then we can add positioning properties**
```
h1{
   background-color: blue;
   position: fixed;
   top: 0;
   margin: 0;
}
```
![[20250522-1201-38.4650983.mp4]]


#### Sticky Position
```
h1{
   background-color: blue;
   position: sticky;
   margin: 0;
   top: 0px
   right: 0px
}
```
![[20250522-1211-55.8724668.mp4]]
It stick to our viewport kapag nasa dulo na sya ng veiw natin and also it won't work if we don't have a position properties like in the video. 


#### Absolute Position
```
h1{
   background-color: blue;
   position: absolute;
   margin: 0;
}
```
![[20250522-1225-12.7604046.mp4]]
In this video we see na katulad ng fixed pumapatong din sya sa mga element, sa madaling salita nawawala din sa layout ang isang element kapag naka absolute, but the difference sya sa fixed, hindi sya sumusunod sa viewport.

note: the viewport is yung nakikita natin sa screen.


#### Relative Position
```
h1{
   background-color: blue;
   position: relative;
   margin: 0;
   top: 200px;
}
```
![[20250522-1239-25.5471051.mp4]]
The relative is sumusunod sa layout, but pwede mong imanipulate yung position nya.
