## Cisco Packet Tracer 

Packet Tracer also provides a variety of tabs for device configuration including the following:

- Physical tab - provides an interface of configuring device such as installing different modules, power on and off and so on.


- Config tab - provides an interface to configure the network credentials.

- CLI tab - command line version of config tab, you can config network credentials using cmd. 

- Desktop tab  - for end devices (PCs, laptop and so on) it provides desktop interface (email, terminal, firewall and so on).

- Services - (for servers only) it allows to configure common server processes (https, http, dhcp, dns and so on).
