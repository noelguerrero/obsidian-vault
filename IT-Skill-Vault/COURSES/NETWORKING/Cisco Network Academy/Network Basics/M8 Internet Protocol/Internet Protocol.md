
### Purpose of an IPv4 Address
- Host needs an Ipv4 address to participate in the internet today.
- Ipv4 address is a logical address that identifies a specific host in a network.

### Octets and Dotted-Decimal Notation

IPv4 addresses are 32 bits in length. Here is an IPv4 address in binary:  
**11010001101001011100100000000001**

the 32 bits are grouped into four 8-bit bytes called octets like this:  
**11010001.10100101.11001000.00000001**

The above binary IPv4 becomes this dotted-decimal representation:  
**209.165.200.1**

IPv4 address Example
192.160.100.10

- The first three octet: 192.169.100 is the network address
- The last octet: 10 is the host unique id

Subnet mask
255.255.255.0
