- **Metal wires within cables** - data encoded into electrical impulses.
- **Glass or plastic fibers within cables** - data encoded into light pulses.
- **Wireless transmission** - data is encoded through frequencies. 
## Three Media Types
- Copper
- Fiber-optic
- Wireless transmission

### Common Network Cables
- Twisted-Pair Cable (UTP cable)
- Coaxial Cable
- Fiber-Optic Cable (can be glass or plastic)
