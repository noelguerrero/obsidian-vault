## Wireless Standard

**IEEE (Institute of Electrical and Electronics Engineers)** - organization that is responsible for wireless technical standard.

WI-FI Alliance - organization that responsible for testing wireless devices from different manufacuturer

### Wireless Settings
This is a router interface that show the wireless settings.
![[Pasted image 20260708125615.png]]

- Network Mode - determines the type of technology that must be supported (ex, 802.11g, 802.11n, or mix mode)
- Network Name (SSID) - Used to identify the WLAN (basically the name of WLAN)
- Standard Channel - specifies the channel over which communication will occur.
- SSID Broadcast - determines if SSID will be broadcast to all devices within ranges.

Note: SSID (Service Set identifier)

## List of router set up
- Change the SSID or the WLAN name
- broadcast the 2.4 GHz (5 GHz is optional)
- Change the administration password
- Change the wireless password
- Add Guest SSID to restrict users to access only the internet
