## Clients and Server

**Servers** - are devices that has a software that provide resources into the computer. 
Example:
- Web Server Software
- File Server Software
- Email Server Software

**Clients** - are devices that has software that enable to request and display the obtained resources from servers.
Example:
- Web browser

But in the modern networks, computer can act client, server, or both. It can be base on software installed on computer determines which computer plays.

### Peer-to-Peer Networks (P2P)
- are two devices that connected to each other both of them can act as client or server. 
- We can create large P2P network by using network devices such as switch to connect multiple devices. 
- But this method didn't used in large corporate because the computer becomes laggy since it plays both client and server at the same time.

Advantages
- Easy to set up
- less complex
- lower cost
- and so on,

Disadvantages
- no centralized administration
- not secure
- not scalable

### Multiple Roles in Network

A Single computer can run multiple server software (such as email, web, and file server) and also a computer can run multiple types of client software such as email, web browser, file access and so on.

## ISP Connectivity Options

### ISP Service
- **ISP (Internet Service Provider)** - provide a link between home network and the internet.
	- It can be local cable provider, landline telephone service provider, cellular network provider.
	- also it offer additional services such as email accounts, network storage, and web hosting, and automated backup or security services.

- ISPs are critical to communication across the global internet. Each ISP connects to other ISPs to form a links that interconnect users all over the world. 
- ISPs connected into hierarchical manner that ensure that internet traffic takes the shortest path from source to destination.
