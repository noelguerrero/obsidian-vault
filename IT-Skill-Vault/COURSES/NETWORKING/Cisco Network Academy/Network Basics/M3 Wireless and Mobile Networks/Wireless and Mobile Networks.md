Mobile phone use radio waves to transmit voice signals to antennas mounted on towers nearby, this type of network called GSM network 

the abbreviations 3G, 4G, 4G-LTE, and 5G is used to describe how fast the data transmission.

In addtionn to the GSM and 4G and 5G transmitters and receivers, smartphones can make connection in variety of ways
- GPS
- Wi-FI
- Bluetooth
- NFC (Near Field Communication) - uses electromagnetic fields to exchange data between device into few centimeters away (Ex. Connecting phone into payment system).
