
## TIPS in Troubleshooting
1. Use **KIS (Keep It Simple)** method 
2. **Make one change at a time** - like coding every changes you do in the system, test it before you proceed to another changes.
3. **Be careful with solution sources** - be mindful on the solutions in the internet. some of the solution on the internet not suitable for you problem.
4. **Document** - document everything when you encounter and solve a problem

## Troubleshoot method
**Use:**
- Safemode - if you can't boot in the normal window state.
- Restore point - if you want to restore a previous state
- Update / remove update
- Resetting - you can reset the device without removing the personal files (note: still back up the files)
