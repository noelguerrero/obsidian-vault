Some times we can run we encounter a problem wherein we can open into windows interface, but when it we boot it into safe mode it becomes fine. So that means there is something wrong in our system configuration

Note: 
- There are many ways to go into safe mode.
- By default safe mode doesn't have network connection, but there is a option that does have.

****
## To Go into Safe Mode

**Option 1**
- Run dialog (Win + R)
- msconfig
- Boot tab
![[Pasted image 20260914211456.png]]
	You can see a few option here 
- Check the boot box 
	- note: the default is minimal which is minimal safe mode
-  Apply and OK

Note:
- minimal - minimal safeboot
- No GUI boot - just a CLI or command line panel
- and so on

****

**Option 2**
- Settings
- Recovery
- Advance start up (click restart now)
- You can see this panel
![[Pasted image 20260914210020.png]]
- Troubleshoot
- Advance option
![[Pasted image 20260914210120.png]]
	You can see there is a lot option you can do.
- Start up settings
- click restart
![[Pasted image 20260914210315.png]]
	You can see there is 3 safe mode options here (4, 5, 6)

Note:
- Go to 4 for simple safe mode
- Go to 5 when you need an internet, like when you need to install drivers.
- Go to 6 when you need a terminal power.

****
**Option 3**
- Hold shift and click the restart button in the interface
![[Pasted image 20260914211120.png]]
and you will go into this advance option panel, then follow the some steps in option 2
****
## To go out into Safe Mode
- Run dialog (Win + R)
- msconfig
- Boot tab
- uncheck the safe boot box
- apply and ok
