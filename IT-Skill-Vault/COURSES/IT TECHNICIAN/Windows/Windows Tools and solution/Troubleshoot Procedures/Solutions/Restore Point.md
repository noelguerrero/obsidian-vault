This tool or function can restore a previous point of devices. This is useful when you are going to install or configure unsafe app or file, this tool can help you retain the previous point when there is bad happen in your device.

Note: 
- Restore point only affects the installed programs and drivers, not the personal files (documents, pictures, etc.) but still back up it.
- You need to create a certain point of your device before you restore it.
- Before you restore your device to previous point, create a restore point for your current device status for back up

**To create an restore point**
- windows search bar
- search: restore point
- create
- name you restore (Recommend: Input also the date of a point)

**To restore**
- windows search bar
- search: restore point
- system restore
- confirm
- click the specific restore point
- click: scan for affected program
- finish

Note: the "scan for affected program" - you can see what program will be uninstalled or change.
