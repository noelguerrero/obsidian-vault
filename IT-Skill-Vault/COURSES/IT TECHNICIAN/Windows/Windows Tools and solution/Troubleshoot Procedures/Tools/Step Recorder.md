- is a built-in windows troubleshooting tool that records the actions you perform on you computer.
- It helps users to document a problem so that the IT support can easily understand and reproduce it.
- it takes screenshots when you perform an action and adds a description of each steps

**Uses of Step Recorder**

| Use                                   | Explanation                                                  | Example                                              |
| ------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------- |
| **Troubleshooting software problems** | Records the exact steps that caused an issue.                | Microsoft Word crashes after clicking "Print."       |
| **Helping IT support**                | Lets users show the problem instead of trying to explain it. | A user sends the recording to the IT department.     |
| **Bug reporting**                     | Developers can reproduce software bugs more easily.          | An app freezes after selecting a specific menu.      |
| **Creating tutorials**                | Records step-by-step instructions with screenshots.          | "How to connect to a Wi-Fi network."                 |
| **Documenting procedures**            | Creates a record of how a task was completed.                | Installing a printer driver or configuring settings. |
| **Training new users**                | Shows beginners the exact sequence of actions.               | Teaching employees how to use company software.      |
