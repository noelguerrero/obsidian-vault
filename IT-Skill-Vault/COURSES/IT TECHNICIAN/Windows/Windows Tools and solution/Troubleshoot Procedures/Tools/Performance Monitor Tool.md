- it is a built-in Windows tool used to monitor, analyze, and troubleshoot the performance of the computer in real time or over a period of time.
- It collects detailed information about hardware, operating system, and application to help identify performance bottlenecks.\

**Main Uses of Performance Monitor**

|Use|Description|
|---|---|
|**Monitor CPU usage**|Track processor usage in real time.|
|**Monitor Memory (RAM)**|Check available memory, paging, and memory pressure.|
|**Monitor Disk Performance**|See disk read/write speed, queue length, and latency.|
|**Monitor Network Activity**|Measure network bandwidth and traffic.|
|**Identify Performance Bottlenecks**|Determine whether CPU, RAM, disk, or network is slowing the system.|
|**Collect Performance Logs**|Save performance data for later analysis.|
|**Create Alerts**|Notify you when a performance counter exceeds a specified threshold.|
|**Analyze Long-Term Performance**|Compare system performance over days or weeks.|

**Main Sections of Performance Monitor**

| Section                 | Purpose                                            |
| ----------------------- | -------------------------------------------------- |
| **Monitoring Tools**    | View performance information in real time.         |
| **Data Collector Sets** | Create and schedule performance data collection.   |
| **Reports**             | View saved performance logs and generated reports. |
