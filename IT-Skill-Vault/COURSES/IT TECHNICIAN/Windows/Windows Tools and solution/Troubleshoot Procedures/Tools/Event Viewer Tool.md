- It is a built-int Windows administrative tool that records system, security, and application events.

**It is use for:**
- Troubleshoot system errors and crashes
- Diagnose application failures
- Monitor security related events (logins, failed logins, account changes)
- Check hardware and driver issues
- Monitor system performance and windows services
- Review what happend before and after a problem occurred

## Tips how to use it
- Go to a certain section you want to monitor then click filter current log.
- configure the filter base on specific logs you wanna catch.
- if you didn't know any info of the log, copy the source and event description and search it in google or ask AI about it.

## Event Viewer Sections

| Section                             | Purpose                                                                   | Common Uses                                                                                                  |
| ----------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Custom Views**                    | Displays filtered events based on specific criteria.                      | Quickly find administrative events, errors, warnings, or custom filtered logs.                               |
| **Windows Logs**                    | Stores the main logs generated by Windows.                                | Troubleshooting Windows, applications, security, and system issues.                                          |
| **Applications and Services Logs**  | Contains detailed logs for Windows components and installed applications. | Diagnose issues with specific Windows features such as DNS, PowerShell, Windows Defender, Hyper-V, and more. |
| **Subscriptions** _(if configured)_ | Collects event logs from remote computers using Windows Event Forwarding. | Centralized monitoring of multiple computers in enterprise environments.                                     |

****
## Windows logs

|Log|Purpose|Examples|
|---|---|---|
|**Application**|Records events generated by applications and software.|Program crashes, Office errors, SQL Server events, browser errors.|
|**Security**|Records security-related activities.|Successful logins, failed logins, account lockouts, password changes, permission changes.|
|**Setup**|Records Windows installation and update events.|Windows Updates, feature upgrades, driver installations.|
|**System**|Records events generated by Windows system components.|Driver failures, hardware problems, service startup failures, unexpected shutdowns.|
|**Forwarded Events**|Stores events forwarded from other computers.|Centralized event collection from remote devices in a network.|


****
## Event Levels

|Level|Description|Example|
|---|---|---|
|**Critical**|A severe problem that requires immediate attention.|System crash, unexpected shutdown.|
|**Error**|An operation failed or a component encountered a problem.|Application crash, driver failed to load.|
|**Warning**|Indicates a potential problem that may require attention.|Low disk space, device warning.|
|**Information**|Records normal successful operations.|Service started successfully, user logged in.|
|**Verbose**|Provides detailed diagnostic information.|Advanced debugging and troubleshooting logs.|

****
## Information found in an event

| Field             | Description                                                              |
| ----------------- | ------------------------------------------------------------------------ |
| **Date and Time** | When the event occurred.                                                 |
| **Level**         | Severity of the event (Critical, Error, Warning, etc.).                  |
| **Source**        | The application, service, or Windows component that generated the event. |
| **Event ID**      | A unique identifier for the event type.                                  |
| **Task Category** | The specific task or operation related to the event.                     |
| **User**          | The user account associated with the event (if applicable).              |
| **Computer**      | The name of the computer where the event occurred.                       |
| **Description**   | Detailed information explaining the event.                               |
