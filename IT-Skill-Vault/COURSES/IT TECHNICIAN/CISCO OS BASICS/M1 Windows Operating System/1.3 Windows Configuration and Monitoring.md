### 1.3.1 Local Users and Domains

A side from not logging as a admin when did not needed, it is a best practices to limit the privilege of a standard user or not give it a admin privilege.

Also disable the guest account, because guest account have default privilege even though it is limited.

**Windows Groups**
- A group of users that can have a name and set of permissions associated with it.
- When a user join a specific groups, it inherit the groups privileges.

![[Pasted image 20261024143200.png]]

Beside user groups to manage permissions use domains.

#### Windows Domain
- It is a centralized network management system that allows organization to manage users, computers, and security setting are managed from a single database.
- This database stored on or more **Domain Controller**

#### Domain Controller (DC)
- A server that manages a Windows Domain
- When user log in, the DC authenticated it before they can access the network resources and getting privileges.

### CLI and PowerShell

#### Windows Command Line Interface (CLI)
- it is a text-based interface that can be used to basic commands such as: run programs, navigate the file system, and folders 
- It is a text-based way to interact with the OS instead of typing.

In addition, files called batch files can be created to execute multiple commands in succession (much like basic script).

**Batch File** 
- It is a text file that contains a list of windows commands to be execute automatically.
- It is uses to automate repetitive task, manipulate files, open multiple programs at once, and so on.
- It uses `.bat` or `.cmd` extension.
 
Ex:
```
@echo off
echo Hello, World!
pause
```


**Few things to remember in CLI**
- It is not case sensitive (by default).
- the drive letter followed by `:` and each level of file is separated by `\`, ex: `C:∖Users∖Jim∖Desktop∖file.txt`
- Two dots `..` to move back on each level of file.
- Commands that have optional option use `/` to choose the option.
- Tab key to auto-complete the command.

Note: CLI have many commands and feature but it cannot work with the core windows command or the GUI.

### Windows PowerShell
- it is a command-line interface (CLI) and scripting language.
- Much powerful that CLI because it can work not just in files but in processes, services, Windows Registry, Active Directory, and many other system components.
- It can also automate complex task using script.

**PowerShell Components**
- Cmdlets – Built-in PowerShell commands that perform a specific task. They can also pass their output (called an object) to another cmdlet, allowing multiple commands to work together.
- PowerShell Scripts (`.ps1`) – Files that contain one or more PowerShell commands. Running a `.ps1` file executes all the commands inside it automatically.
- PowerShell Functions – Reusable blocks of PowerShell code that perform a specific task. Instead of writing the same commands repeatedly, you can create a function and call it whenever you need it.

**Note: to know see information about the commands in PowerShell**
```PowerShell
help
```

### 1.3.4 Windows Management Instrumentation (WMI)
- It is used to manage remote computers.
- It can retrieve computer information such as components, hardware and software statistics, and monitor health of the remote computers.

![[Pasted image 20261024201905.png]]

**4 Tabs of WMI**
- **General -** Summary information about the local computer and WMI
- **Backup/Restore -** Allows manual backup of statistics gathered by WMI
- **Security -** Settings to configure who has access to different WMI statistics
- **Advanced -** Settings to configure the default namespace for WMI

**WMI access should be limited** Because:
- Attacks today use WMI to connect to remote systems, modify registry, and run commands.
- WMI traffic does not detect because it is common traffic and not leaving an evidence.

### 1.3.5 Net Command
- It is command prompt used to manage and view network resources, users, groups, share folders, and services on computer or network.
- To see information about net commands, cmd:`net help`

**Example Net Commands**
- `net accounts` - Sets password and logon requirements for users.
- `net session` - lists or disconnects sessions between  computers on the network.
- `net share` - Creates, remove, or manages shared resources.
- `net start` - Starts a network service or lists running network services.
- `net stop` - Stop a network service.
- `net use` - Connects, disconnects, and displays information about shared network resources.
- `net view` - Shows a list of computers and network devices on the network.

### 1.3.6 Task Manager and Resource Monitor
These tools are useful when investigating a problem where malware is suspected.

#### Task Manager
- it is a built-in Windows system utility that monitor and mange running applications, processes, services, and system performance.
- You can see how much CPU, memory, disk, and network resources are being used.

![[Pasted image 20261024203448.png]]

#### Task Manager Tabs
**Processes**
- List all of the program and processes that are running.
- Display CPU, memory, disk, and network resources use of each application.
- Process can examined or terminate.

**Performance**
- View performance statistics, it provides overview of the CPU, memory, disk, network performance, and so on.

**App History**
- It display resource used by the application overtime, it provides insights that application consuming much resources than they should do.

**Startup**
- Display the application and services that automatically runs after boot.

**Users**
- Display all the users that are logged on, and see the application and processes are using.

**Details**
- Similar to processes tab, but provides additional management options such as priority that can priority a specific process, and Analyze wait chain feature.
- **Analyze wait chain** 
	- it is a feature that identify why programs is no responding. 
	- It checks whether a process is waiting for another process or thread to finish before it can continue.

**Services**
- It display all the services that running and its PID and description.

#### Resource Monitor 
- is a built-in Windows troubleshooting tool that provides a more detailed view of how computer's resources are being used.
- It lets you see which process of application is using your CPU, memory, disk, and network.

![[Pasted image 20261026125502.png]]

##### Five Tables of Resource Monitor

| **Section**  | **What it shows**                                                                                                      |
| ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| **Overview** | A summary of CPU, Memory, Disk, and Network usage, including real-time graphs and the processes using these resources. |
| **CPU**      | CPU usage, running processes, services, threads, and processor activity.                                               |
| **Memory**   | RAM usage, available memory, hard faults, and memory allocation for each process.                                      |
| **Disk**     | Disk activity, read/write operations, active files, and storage performance.                                           |
| **Network**  | Network usage, send/receive activity, TCP connections, listening ports, and network activity.                          |
