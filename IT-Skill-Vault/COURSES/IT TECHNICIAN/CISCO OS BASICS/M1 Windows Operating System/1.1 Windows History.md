#### Old Computer (MS-DOS-based Windows)
- **MS-DOS** was the actual operating system that controlled the computer and its hardware.
- Early versions of Windows (such as Windows 1.0 and Windows 3.1) were **graphical interfaces (GUI)** that ran **on top of MS-DOS**.
- Users could use the mouse and windows, but MS-DOS still handled the system in the background.
- Typically supported **one user** and had limited multitasking capabilities.

**Architecture
```
User
   ↓
Windows GUI (just a graphical shell)
   ↓
MS-DOS (the real OS)
   ↓
Hardware (CPU, RAM, Disk, etc.)
```

#### Modern Computer (Windows NT-based)
- Modern Windows (Windows XP, Vista, 7, 8, 10, and 11) is built on the **Windows NT (New Technology)** operating system.
- **Windows NT** directly controls the computer's hardware without relying on MS-DOS.
- Supports **multiple users**, **multitasking**, improved **security**, **memory management**, and **system stability**.
- Command Prompt (`cmd`) still exists, but it is **not MS-DOS**—it is simply a Windows program that provides a command-line interface.

**Architecture**
```
User
   ↓
Windows 10 / Windows 11
   ↓
Windows NT Kernel
   ↓
Hardware
```


#### MS-DOS Command

|**Command**|**Example**|**What it Does**|
|---|---|---|
|`dir`|`dir`|Lists all files and folders in the current directory.|
|`cd directory`|`cd Documents`|Moves into the **Documents** folder.|
|`cd ..`|`cd ..`|Moves up one folder level.|
|`cd \`|`cd \`|Returns to the root of the drive (e.g., `C:\`).|
|`copy source destination`|`copy notes.txt D:\Backup`|Copies `notes.txt` to the `D:\Backup` folder.|
|`del filename`|`del test.txt`|Deletes `test.txt`.|
|`find`|`find "Hello" notes.txt`|Searches for the word **Hello** inside `notes.txt`.|
|`mkdir directory`|`mkdir Projects`|Creates a folder named **Projects**.|
|`ren oldname newname`|`ren old.txt new.txt`|Renames `old.txt` to `new.txt`.|
|`help`|`help`|Displays all available MS-DOS commands.|
|`help command`|`help dir`|Shows detailed information about the `dir` command.|

### Operating System Vulnerabilities
Even the OS can have vulnerabilities coming from the attacker.

#### Common Window OS Security Recommendation

**1. Virus or Malware Protection**
- By default windows uses Windows defender that provides protection tools built into the system.
- Disabling it can open a vulnerabilities in Windows

**2. Unknown or Unmanage Services**
- The service or application that run behind the scene.
- It is crucial to make sure all of the services install are safe, because unknown service is vulnerable to attack.

**3. Encryption**
- the data that is not encrypted, is easily be gathered and exploited.

**4. Security Policy**
- Security Policy is a set of rules that controls how Windows secures the operating system, user accounts, passwords, devices, and access to resources.
- A good policy must be configured to prevent possible attacks.

**5. Firewall**
- Some firewall rules is outdated, so it is important to review firewall settings periodically to ensure that the rules and applicable and remove rules that no longer apply.

**6. File and Share Permission**
- It is best to provide each user or group a minimum access to specific file or folders.

**7. Weak or No Password**
- It is important to make sure that an account specially a administrator account have strong password.

**8. Login as Administrator**
- Administrator account have all the priviledge, It is best to login as a standard user and only use an Administrator account to accomplish certain tasks.
