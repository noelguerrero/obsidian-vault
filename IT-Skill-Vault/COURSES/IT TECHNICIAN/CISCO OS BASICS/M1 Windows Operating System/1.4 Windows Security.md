
### 1.4.1 The `netstat` Command
When there is a malware, it open communicaton ports on the host to send and receive data.

The `netstat` command can be used to look for inbound and outbound connections that are not authorized then terminate it using task manager.

Example: `nestat -abno`

### 1.4.3 Windows Update Management 
There are zero-day exploits (a malware that develop early and didn't have a counter measure) that can penetrate and damage the OS.

To ensure the highest level of protection make sure the windows is up to date.

### 1.4.4 Local Security Policy
- It is a built it windows management tool that allows an administrator to configure security settings for the local computer. 
- These settings determine how user authenticate, what actions they are allowed to perform, and how windows protects the system.
- It only affects the current computer, unlike Group Policy, which can manage multiple computers in a windows domain.

![[Pasted image 20261030203557.png]]
there are several security policies in different section that can configure, and there are also an export feature wherein you can export the security policy and import it to the other computer.

### 1.4.5 Windows Defender
Malwares are designed to damage the computer, it is important to protect your device using antimalware software.

#### Types of antimalware software programs
- **Antivirus Protection** - it is a program that monitors and quarantine the virus and also it warns the user when it detects something.
- **Adware Protection** - it is a program that looks for adwares in the computer.
- **Phishing Protection** - It block the IP address of phishing sites and warns the user about suspicious sites.
- **Spyware Protection** - It scan for keyloggers and other spywares.
- **Trusted / Untrusted Sources** -It is a program that warns you about the unsafe software that installed or unsafe website that you visit.

#### Windows Defender
- It is a built-in windows  antimalware tool that protects the computer to any malware.

****
### Windows Defender Firewall
- It is a windows security feature that monitors and filters network traffic that entering and leaving the computer.
- It protects the system by allowing the trusted connections and blocking unauthorized or potential harmful ones based on the firewall rules.
