
### 2.1.1 What is Linux
- It was created in 1991
- It is a open-source, fast, reliable, and small 
- It require very little hardware resources to run and it is highly customizable.
- you will found it anywhere from wristwatch to supercomputers.

Linux is designed to be connected to the network , which makes simpler to write and use network-based applications.

**Linux distribution** (or distros)
- it is a term used to describe Linux package created by different organization 
- it includes Linux kernel with customized tools and software package
- Some of example of Linux distribution (distros): Debian, Red Hat, Ubuntu, CentOS, SUSE and more


****
### 2.1.2 The Value of Linux
Linux is a OS used in Security Operations Center (SOC).

**There are some reason:**
- **Linux is open source** - it is flexible it allows analyst and administrators to tailor-build the OS specifically for the security analysis.
- **Linux CLI is very powerful** - it enables analyst to perform task not only directly on the terminal, but remotely.
- **User has more control over the OS** - the root user have an absolutely power over the computer. Unlike other OS the root user can modify any aspect of the computer with a few keystrokes.
	- This ability is valuable when working on the low level functions such as the network stack. It allows the root user to have control over the way network packets are handled by the OS.
- **It allows for better network communication control** - the OS can be adjusted in every aspect, it is a great platform for creating network applications.
	- This is the reason why many network-based software tools are available for linux only.


****
### 2.1.3 Linux in the SOC
Flexibility of Linux is a great feature for the SOC. The OS can be tailored specifically for security analysis platform. 

**Example:**
- Administrators can only add necessary package to the OS, making it lean and efficient. Specific software tools can be installed and configure to work in conjunction, allowing administrator  to build a customize computer for SOC.

It is an open source suite of tools that work together for network security analysis.

**Other tools found in SOC**
- **Network packet capture sofware**
	- A crucial tool for SOC analyst as it makes it possible to observe and understand every detail of network transactions.
	- Ex: Wireshark - it is the popular packet capture tool.
- **Malware analysis tools** - this tool allow analysist and observe malware without the risk of compromising the system.
- **Intrusion detection systems (IDSs)**
	- These tools are used for real-time traffic monitoring and inspections.
	- if any aspect of the currently flowing traffic matches the rules set in IDS, the specific action set will be taken.
- **Firewalls** - tools that filter network traffic, it decide what traffic should enter or leave in the network device.
- **Log managers** - it is used to record every events, because network can generate a very large number of log entries, log manager software is employed to facilitate log monitoring.
- **Security Information and Event Management (SIEM)** - it provides real-time analysist of alerts and log entries generated by network appliances such as IDS and firewalls.
- **Ticketing Systems** - ticketing assignment, editing, and recording is done through ticketing management system. Security alerts are often assigned to analysts through ticketing system.

### 2.1.4 Linux Tools 
In addition to SOC-specific tools, Linux computers that are used in SOC often contain penetrations tools, also known as PenTesting.

A pen testing a test of process of looking for vulnerabilities in a network or computer by attacking it.

Packet generators, port scanners, and proof-of-concept (PoC) exploits are example of PenTesting tools.
